> **این پوشه حالا داخلِ پروژه است:** `Cheghar/dataset/`
> مدیای نهایی (۱۳۲۴ گیف + ۱۳۲۴ عکس، ۴۶۸ مگابایت) در بک‌اند نشسته و سرو می‌شود:
> `Cheghar/backend/gym/media/exercise_library/`

```
Cheghar/dataset/
├── README-fa.md                   همین فایل

│   ├── steps_fa.json              ۴۴۱۴ جملهٔ آموزشیِ ترجمه‌شده
│   └── unknown_terms.txt          واژه‌هایی که هنوز ترجمه نشده‌اند
└── tools/

    ├── brand_media_hq.py          ساختِ دوبارهٔ مدیای باکیفیت (لوگودار)
    ├── merge_sources.py           افزودنِ حرکت‌های تازه از منبعِ دیگر
    └── chagher_api.py             سرویسِ FastAPI برای آپلود به بک‌اند
```

**انجام شد:** هر ۱۳۲۴ حرکت + هر ۱۳۲۴ گیف و عکس روی سرور نشست (آپلود کامل، بی‌خطا)
و صفحهٔ آموزشِ هر حرکت در `/chagher/exercise/<شناسه>/` باز می‌شود. در PDFِ برنامه‌ها
نامِ حرکت به همین صفحه لینک است. شرحِ کامل: `Cheghar/CHANGELOG-fa.md`

## ۱) فارسی

- **نامِ هر ۱۳۲۴ حرکت** فارسی شد: ۱۰۳۳ مطمئن، ۱۴۹ نیمه، ۱۴۲ نیازمندِ بازبینی (`name_fa_quality`).
- **برچسب‌ها** (دستگاه، عضلهٔ هدف، عضله‌های کمکی، بخشِ بدن) صددرصد فارسی.
- **متنِ آموزش**: هر ۷۷۱۰ جملهٔ گام‌به‌گام فارسی شد (۴۴۱۴ جملهٔ یکتا، با هوش مصنوعیِ خودِ چغر
  ترجمه و با واژه‌نامهٔ بدن‌سازی یکدست شد). هیچ جمله‌ای بدونِ ترجمه نماند.

نمونه — «پرس سینه با هالتر»:

> صاف روی میز دراز بکش، کف پاها را روی زمین بگذار و پشتت را به میز بچسبان.
> هالتر را با دست از رو و کمی بازتر از عرض شانه بگیر. …

**بهتر کردنِ نام‌ها:** `unknown_terms.txt` را باز کنید، معادلِ فارسیِ واژه‌ها را در
`terms_fa.json` بنویسید و دوباره بسازید:

```bash
python build_chagher_dataset.py
```

## ۲) API — فرستادن به بک‌اندِ اصلی

**سمتِ سرور** (انجام شد): کتابخانهٔ حرکت‌ها به بک‌اندِ جنگو اضافه شد —
مدلِ `ExerciseLibrary`، صفحه در پنلِ ادمین، و چهار مسیر:

| مسیر | کار |
|---|---|
| `POST /chagher/api/exercise-library/import/` | ورودِ بسته‌ایِ حرکت‌ها (تکراری نمی‌سازد) |
| `POST /chagher/api/exercise-library/<id>/media/` | آپلودِ گیف و عکس |
| `GET /chagher/api/exercise-library/status/` | چه چیزی قبلاً رفته است |
| `GET /chagher/api/exercise-library/?search=&equipment=` | فهرست برای اپ |

**توکنِ مدیر** (کاربر `09380425971`):

```
2ae1f02c4113e34bba96f364237bb6156f609bbf
```

**سمتِ این کامپیوتر:**

```bash
pip install fastapi uvicorn httpx     # یک‌بار
cd chagher-dataset
python chagher_api.py                 # → http://127.0.0.1:8800
```

مرورگر را روی `http://127.0.0.1:8800` باز کنید: آدرسِ بک‌اند و توکن را بگذارید و
«شروع آپلود» را بزنید. دکمهٔ «آزمایشِ ۵ تایی» هم هست. پیشرفت زنده نشان داده می‌شود.

بدونِ مرورگر:

```bash
curl -X POST http://127.0.0.1:8800/push -H "Content-Type: application/json" \
  -d '{"target":"http://185.239.3.189:8000/chagher","token":"2ae1f02c...","limit":0}'
```

- آپلود **قابلِ ادامه** است؛ چیزی که رفته دوباره فرستاده نمی‌شود.
- **آزموده شد:** ۵ حرکت + ۵ گیف + ۵ عکس در ۲۴ ثانیه روی سرورِ واقعی نشست.
- کلِ ۱۳۲۴ تا حدود **یک تا دو ساعت** طول می‌کشد (۴۶۸ مگابایت مدیا).
- همین برنامه دیتاست را محلی هم سرو می‌کند: `/exercises`، `/exercises/{id}`، `/media/gif/{id}.gif`.

## ۳) کیفیتِ مدیا

| | قبل | حالا |
|---|---|---|
| گیف | ۱۸۰×۱۸۰ | **۳۶۰×۳۶۰** |
| عکس | ۱۸۰×۱۸۰ | **۵۱۲×۵۱۲**، کیفیت ۹۲ |
| پالتِ رنگ | هر فریم جدا (لرزشِ رنگ) | پالتِ مشترکِ همهٔ فریم‌ها |
| لوگو | ۳۴ پیکسل، محو | **۶۴ پیکسل، تیز، با سایهٔ متن** |

بزرگ‌نمایی با LANCZOS + شارپِ کنترل‌شده انجام شده است.

> **سقفِ کیفیت:** فایل‌هایی که ما داریم از پایه ۱۸۰×۱۸۰ هستند؛ بزرگ‌نمایی بیشتر از این،
> تصویر را نرم و مات می‌کند. حالا که از **Gym Visual خرید کرده‌اید**، نسخهٔ اصلیِ
> پرکیفیت (۱۰۸۰ یا ویدیو) را از پنلِ خودشان بگیرید و به من بدهید تا همه‌چیز را از رویِ
> همان بسازم — آن وقت کیفیت واقعاً چند برابر می‌شود، نه بزرگ‌نماییِ تصویرِ کوچک.

## ۴) کامل‌کردنِ فهرست

الان ۱۳۲۴ حرکت و ۲۸ وسیله داریم. برای «هیچ حرکت و دستگاهی جا نماند»:

- **راهِ درست:** بستهٔ خریداری‌شدهٔ Gym Visual (کاتالوگشان چند هزار حرکت دارد، با همین سبکِ
  سه‌بعدی). پوشه‌اش را بدهید و یک دستور بزنید:

  ```bash
  python merge_sources.py --src "D:\GymVisual" --style 3d --dry-run
  python merge_sources.py --src "D:\GymVisual" --style 3d
  ```

  اسکریپت خودش تکراری‌ها را با نامِ ساده‌شده تشخیص می‌دهد و رد می‌کند، به تازه‌ها شناسهٔ
  جدید می‌دهد، نامشان را فارسی می‌کند و مدیا را سرِ جایش کپی می‌کند. گزارش در `merge_report.txt`.

- **راهِ دوم (سبکِ متفاوت):** دیتاستِ آزادِ `free-exercise-db` — سنجیدم: **۶۷۰ حرکتِ تازه**
  دارد که ما نداریم (مثلِ دستگاهِ کرانچ، فوم‌رولر، حرکاتِ کتل‌بل و کششی). ولی مدیایش
  **عکسِ آدمِ واقعی** است، نه انیمیشنِ سه‌بعدی؛ اگر اضافه شود، ظاهرِ اپ دوتکه می‌شود.
  با `--style photo` قابلِ افزودن است و در هر رکورد علامت می‌خورد.
