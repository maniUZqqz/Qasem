همین اطلاعات بعداً پایه‌ی هر جمله‌ای است که سیستم به مشتری شما می‌گوید.

تحلیل محصول و رقبا

عکس محصول خوانده می‌شود و قیمت رقبا از وب درمی‌آید.

دیجی‌کالا، ترب و جستجوی وب — منبع و زمان هر داده ذخیره می‌شود تا قابل بازبینی باشد.

پوستر و تصاویر
