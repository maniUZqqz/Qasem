# آزمونِ مرورگریِ «شخصیتِ برند» (Playwright)

دو اسکریپت که روی یک نمونهٔ در حالِ اجرا (پنل + API) می‌زنند؛ هر دو خروجیِ PASS/FAIL و کدِ خروج دارند:

* `ui_flow.py` — نمای کلی، شخصیتِ گفتار (جادوگر، ذخیره، بلوکِ تزریق)، ویرایشگر (کشیدنِ لایه، برگشت/جلو، قرینه، Ctrl+Z، ذخیره)، ژست و صحنه (پیش‌نمایش، کلیدِ رنگ، ۱۰ قالب)،
  گالری (۶ کارتِ کاربرد)، خروجی (۵ کارت)، صندوقِ پیام؛ روی دسکتاپ و گوشی، روشن و تیره؛ بدونِ اسکرولِ افقی و بدونِ خطای کنسول.
* `ui_integration.py` — چتِ آزمایشی (نوارِ لحن + آواتار + سلام)، تامنیل‌ساز (دکمهٔ «شخصیتِ برند»)، استودیوی تصویر (۱۰ قالب)، موشن (تحویل از گالری + کتابخانهٔ قطعه‌ها)، کارگردان (۵ استیکر).

اجرا (متغیرها: `BC_BASE` نشانیِ پنل مثلاً `http://127.0.0.1:5184`، `BC_STORE` شناسهٔ فروشگاه، `BC_USER` و `BC_PWD` کاربرِ آزمایشیِ مدیر، `BC_PRODUCT` شناسهٔ یک محصولِ همان فروشگاه):

    PLAYWRIGHT_BROWSERS_PATH=... python ui_flow.py
