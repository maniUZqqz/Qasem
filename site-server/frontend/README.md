# پنل آپ‌مارکت — فرانت‌اند

React + Vite + TypeScript + Tailwind v4 · فارسی، راست‌به‌چپ.

این پنلِ پشتِ لاگین است. سایت عمومی بازاریابی جای دیگری است:
[`../website`](../website).

## اجرا

```powershell
npm install
npm run dev        # http://localhost:5173
```

سرور توسعه `‎/api` و `‎/media` را به جنگو روی `http://localhost:8000` پراکسی
می‌کند (`vite.config.ts`) — **اول بک‌اند را بالا بیاور**. روی میزبان دیگر،
`target` را عوض کن.

آسان‌ترین راه: `..\start.bat` که هر سه سرویس را با هم بالا می‌آورد.

```powershell
npm run build      # tsc --noEmit + باندل production در dist/
```

## نقشه‌ی کد

| مسیر | چیست |
|---|---|
| `src/App.tsx` | **تنها فهرست مسیرها.** هر صفحه‌ای که اینجا نباشد وجود ندارد |
| `src/components/Layout.tsx` | قاب و سایدبار — و **تنها فهرست ناوبری** |
| `src/components/ui.tsx` | اجزای پایه: دکمه، کارت، جدول، برچسب… |
| `src/components/charts.tsx` | کاشی آمار و نمودار، با پالت اعتبارسنجی‌شده |
| `src/components/Icon.tsx` | آیکون‌های SVG دست‌ساز (بدون وابستگی) |
| `src/index.css` | کل سیستم طراحی: توکن‌های تم تیره/روشن + کلاس‌های `u-*` |
| `src/features/<دامنه>/` | صفحه‌ها، گروه‌بندی‌شده بر اساس دامنه |
| `src/api/client.ts` | نمونه‌ی axios، رفرش توکن، صفحه‌بندی |

> **فهرست صفحه‌ها اینجا نوشته نمی‌شود، و این عمدی است.**
> نسخه‌ی قبلی این فایل چهار مسیر را فهرست کرده بود؛ وقتی پروژه به ده‌ها مسیر
> رسید، این فایل هنوز همان چهارتا را می‌گفت — یعنی یک سند که فعالانه دروغ
> می‌گفت. فهرست واقعی یک جا زندگی می‌کند: `src/App.tsx`. (عددش را
> `دیتا/0-منبع/check.py` می‌سنجد، پس اینجا هم نوشته نمی‌شود.)

## دو قاعده‌ای که شکستنشان گران تمام می‌شود

**۱. صفحه‌ی جدید باید در سایدبار هم بیاید.** شش صفحه‌ی کامل و تست‌شده یک
دوره در روتر بودند و در هیچ منویی نه — یعنی کاربر هیچ راهی به آن‌ها نداشت.
قابلیتی که از منو پیدا نشود، ساخته نشده؛ فقط هزینه‌اش داده شده.

**۲. رنگ را مستقیم ننویس.** از توکن‌های `var(--text)`، `var(--surface)`،
`var(--brand)` استفاده کن. کلاس‌های `slate-*` و `violet-*` تیلویند هم به
همین توکن‌ها وصل شده‌اند و در تم تیره وارونه می‌شوند، پس آن‌ها هم امن‌اند —
ولی یک `#1e293b` هاردکد، روی تم تیره یک لکه‌ی نامرئی می‌سازد.

## نکته‌ها

- توکن‌ها در `localStorage`اند؛ کلاینت axios روی ۴۰۱ خودش رفرش می‌کند و اگر
  رفرش هم نشد به `/login` می‌فرستد. **۴۲۹ و خطای شبکه نشست را تمام
  نمی‌کنند** — یک محدودیت نرخ نباید کسی را که توکن معتبر دارد بیرون بیندازد.
- کارهای سنگین AI به سیستم اصلی نیاز دارند (Ollama + Redis + Celery). روی
  دستگاه بدون آن‌ها، بک‌اند صادقانه `503 queue_unavailable` برمی‌گرداند.
