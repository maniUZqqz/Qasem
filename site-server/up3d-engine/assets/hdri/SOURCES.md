# HDRI lighting environments (Poly Haven, CC0)

Four 1K Radiance HDR files mirrored for the engine's HDRI lighting presets (assets/lighting/hdri_*). Poly Haven publishes every HDRI under
**CC0 1.0 (public domain)** - no attribution is required; the authors are named here anyway. Source files are the 1k `.hdr` versions
(`https://dl.polyhaven.org/file/ph-assets/HDRIs/hdr/1k/<name>_1k.hdr`), downloaded 2026-11-13 (1405/08/23) and stored here unchanged under
the short name `<name>.hdr`. They travel with the node's code package (`processing/assets/hdri`), so no download is needed on the GPU computer.
