Campaigns and automatic publishing

From generation to publication, with human approval in the middle.

The problem

Making the content is half the job. The other half is where, when and in what order it goes out — and making sure nothing leaves without permission.

What it does

  • Group poster, video and caption into one campaign
  • An approval cycle: draft to approved to published
  • Publish straight to Instagram
  • Per-platform delivery status

How it works

A campaign groups content for one product

The system checks that every item in a campaign belongs to the same product.

Publishing happens only after approval

There is no path by which content goes out without you approving it.

Each platform's status is tracked separately

If one fails, the others are not posted again.
