# ویرایشگرِ ویدیو (PersianAiKit.Video)

همهٔ کارهایی که ویدیو را بهتر می‌کنند — رنگ و نور مثلِ لومتری، تثبیتِ لرزش، قابِ عمودیِ ریلز، بُرش و حذفِ مکث‌ها، سرعت و محو، پاک‌سازی و هم‌سطح‌سازیِ صدا مثلِ Essential Sound، و خروجی برای هر جا — در **دو قالب با یک موتور** (همان ایدهٔ ویرایشگرِ عکس):

1. **پریمیرِ وب** — ویرایشگرِ فارسی در مرورگر (`http://localhost:5680`): خطِ زمان با نوارِ فریم‌ها و موجِ صدا، دستگیره‌های بُرش، حذفِ بازه، اسکوپ‌های لومتری (هیستوگرام، موج‌نما، برداری‌نما)، پخشِ پیش‌نمایشِ ویرایش‌شده، برگرداندن.
2. **ابزار برای هوشِ مصنوعیِ بینا** — همان ابزارها به شکلِ یک «نسخهٔ ویرایش» (JSON). هوشِ مصنوعی فیلم نمی‌بیند: یک تصویرِ ۲×۲ از چهار لحظه (~۲۰KB) و اندازه‌گیری‌های تصویر و صدا را می‌بیند و فقط نسخه را می‌نویسد ⇒ **ارزان**. جزئیات: **[AI.md](AI.md)**.

موتورِ سنگین **FFmpeg** است (برنامهٔ جدا)؛ برنامهٔ ما نسخهٔ ویرایش را به زنجیرهٔ فیلترهای FFmpeg تبدیل می‌کند. رنگ و نور **همان ریاضیِ ویرایشگرِ عکس** است و در یک LUTِ سه‌بعدی خلاصه می‌شود (دقیقاً کاری که لومتری می‌کند) ⇒ عکس و ویدیو یک رنگ دارند.

```
project Video\
├─ Run-Server.bat          ← ویرایشگرِ وب + API  (http://localhost:5680 — مرورگر خودش باز می‌شود)
├─ Run-SelfTest.bat        ← آزمونِ نصب (سبک: کلیپ‌های ساختگیِ چندثانیه‌ای، ~۳۰ ثانیه، زیرِ ۲۰۰MB حافظه)
├─ README.md  AI.md  FEATURES.md (فهرستِ کاملِ ابزارها؛ از روی کد ساخته می‌شود)
├─ src\PersianAiKit.Video\          موتور: VideoRecipe، ToolCatalog، Presets، Engine\* (FFmpeg، LUT، زنجیره، سنجش)، Ai\*
├─ src\PersianAiKit.Video.Server\   سرویس + wwwroot (صفحهٔ وب)
├─ src\PersianAiKit.Video.SelfTest\ آزمون
├─ samples\demo.mp4        نمونهٔ ۱۰ ثانیه‌ای (رنگِ کمی تیره و گرم، صدا با مکث، نویز و وزوزِ ۵۰ هرتز)
├─ research\               فهرستِ ۳۶۷ قابلیتِ پریمیر (Premiere_Features_FA.xlsx) و خلاصه‌اش (EditVideo.txt)
├─ tools\Install-FFmpeg.ps1
└─ data\                   کتابخانه (videos\<id>\: اصل، نسخه، خروجی‌ها) و LUTها (luts\)
```

## شروعِ سریع

1. [.NET 8 SDK](https://dotnet.microsoft.com/download) (یا بالاتر) و **FFmpeg**: `powershell -ExecutionPolicy Bypass -File tools\Install-FFmpeg.ps1` (اگر پیدا شد کاری نمی‌کند؛ روی این کامپیوتر نصبِ winget پیدا شد).
2. `Run-SelfTest.bat` — هر ابزار روی ویدیو و صدای ساختگی با جوابِ معلوم؛ آخرش «همه درست است ✓».
3. `Run-Server.bat` — مرورگر روی `http://localhost:5680` باز می‌شود. ویدیو یا صدا را روی صفحه بکشید (یا «باز کردنِ ویدیو»).

## ۱. پریمیرِ وب

| بخش | چه دارد |
|---|---|
| **نمایشگر و خطِ زمان** | فریمِ ویرایش‌شده در هر لحظه؛ «▶ پخش» یک پیش‌نمایشِ ۶ ثانیه‌ایِ ویرایش‌شده (با صدا، تثبیت، سرعت و بازه‌های حذفی) می‌سازد و پخش می‌کند. خطِ زمان: نوارِ ۱۲ فریم + موجِ صدا؛ دستگیره‌های زرد = بُرشِ سر و ته؛ Shift + کشیدن = انتخابِ بازه ⇐ «✂ حذفِ انتخاب»؛ بازه‌های قرمز = حذف‌شده (کلیک ⇐ انتخاب ⇐ «↩ برگرداندن»). |
| **رنگ** | اسکوپ‌ها (هیستوگرام، موج‌نما، برداری‌نما با خطِ پوست)، «✦ خودکار»، و ۵۰ لغزنده: نور، **منحنیِ RGB**، رنگ، HSL در ۸ خانوادهٔ رنگ، رنگ‌دهیِ سایه/روشنی، سطوح و گاما، جزئیات (شارپ، وضوح، نویزگیری)، افکت (وینیت، دانه)، لنز؛ و **LUT** (بارگذاریِ .cube، ورودی برای فیلمِ لاگ یا لوک با شدت). |
| **پریست** | ۹ لوکِ رنگ با پیش‌نمایش روی همان فریم، ۳ پریستِ صدا (پاک‌سازیِ گفتار، گفتار در محیطِ پرسروصدا، موسیقی)، ۶ پریستِ خروجی (ریلز، مربع، یوتیوب، تلگرام، GIF، پادکست). |
| **قاب** | نسبتِ خروجی (۹:۱۶ ریلز/استوری، ۱:۱، ۴:۵، ۱۶:۹) با «بریدن» (مرکز را روی تصویر کلیک کنید)، «زمینهٔ محو» یا «نوارِ سیاه»؛ برش از چهار طرف، چرخش برای صاف کردنِ افق، قرینه؛ **تثبیتِ لرزش**. |
| **زمان** | بُرشِ سر و ته (عدد یا «از همین‌جا»)، سرعت ۰٫۲۵× تا ۴× (صدا بی تغییرِ زیر و بمی)، آهسته‌نمایشِ نرم، محوِ ابتدا و انتها، **حذفِ مکث‌ها** (آستانه خودکار از کفِ نویزِ همان فایل)، فهرستِ بازه‌های حذف‌شده. |
| **صدا** | سنجش (بلندی LUFS، قله، کفِ نویز، وزوزِ برق، سکوت)، «✦ خودکارِ صدا»، هم‌سطح‌سازی (‎−۱۴ وب، ‎−۱۶ پادکست، ‎−۲۳ تلویزیون)، حذفِ وزوزِ ۵۰/۶۰ هرتز، بی‌صدا، و ۹ لغزنده: بلندی، غرش، نویز، کلیک، سین، بم، وضوحِ گفتار، درخشش، یکدست کردن. |
| **خروجی** | پریست‌ها، MP4 (H.264 یا H.265)، WebM، GIF، MP3، WAV؛ اندازه (۴K تا ۴۸۰)، فریم در ثانیه، کیفیت، محدودهٔ پخشِ تلویزیونی؛ نوارِ پیشرفت، لغو، و فهرستِ خروجی‌ها برای دانلود. |
| **هوشِ مصنوعی** | هدف را بنویسید («ریلزِ اینستاگرام با صدای واضح») ⇒ نسخه ساخته می‌شود؛ مدل، دورها و توکن‌ها نشان داده می‌شود. |

کلیدها: **فاصله** پخش/توقف · **← →** یک فریم (با Shift یک ثانیه) · **I** / **O** بُرشِ سر و ته · **Delete** حذفِ انتخاب/برگرداندنِ بازه · **Ctrl+Z / Ctrl+Y** · نگه داشتنِ **`\`** = فریمِ اصل. همه‌چیز خودکار ذخیره می‌شود؛ پیوندِ مستقیم: `http://localhost:5680/#video=<id>&tab=audio`.

## ۲. «نسخهٔ ویرایش» (Recipe)

```json
{
  "preset": "voice",
  "trim": { "start": 1.5, "end": 42 },
  "cuts": [ { "start": 10.2, "end": 11.0 } ],
  "time": { "speed": 1.25, "fadeIn": 0.5, "fadeOut": 1 },
  "adjust": { "exposure": 0.3, "temperature": -8, "sharpen": 30, "noise": 40, "presence": 3 },
  "curve": { "rgb": [[0,0],[70,55],[190,210],[255,255]] },
  "lut": { "file": "slog3-to-709.cube", "mode": "input" },
  "crop": { "angle": 1.2 },
  "frame": { "aspect": "9:16", "fit": "blur" },
  "stabilize": { "amount": 50 },
  "audio": { "normalize": -14, "hum": 50 },
  "output": { "format": "mp4", "codec": "h264", "size": 1080, "quality": "standard" }
}
```

زمان‌ها به ثانیه و روی فایلِ اصلی‌اند. هر چه نیامده = بی‌اثر؛ کلیدِ ناشناخته دور ریخته و عددِ بیرون از بازه بریده می‌شود. فهرستِ کامل: **[FEATURES.md](FEATURES.md)**.

**ترتیبِ تصویر:** درهم‌رفتگی (خودکار) ⇐ HDR به SDR (خودکار، مثلاً ویدیوی آیفون) ⇐ تثبیت ⇐ حذفِ بازه‌ها ⇐ سرعت ⇐ لنز ⇐ چرخش، برش، قرینه ⇐ نویزگیری ⇐ LUTِ رنگ ⇐ وضوح ⇐ شارپ ⇐ وینیت، دانه ⇐ قاب ⇐ اندازه ⇐ محدودهٔ پخش ⇐ محو.
**ترتیبِ صدا:** حذفِ بازه‌ها ⇐ سرعت ⇐ غرش ⇐ وزوزِ برق ⇐ کلیک ⇐ نویز ⇐ سین ⇐ اکولایزر ⇐ کمپرسور ⇐ بلندی ⇐ هم‌سطح‌سازی ⇐ محو.

چند نکتهٔ فنی که کیفیت را نگه می‌دارد:
- **رنگ در یک LUTِ ۳۳×۳۳×۳۳** با درون‌یابیِ چهاروجهی ⇒ همهٔ ابزارهای رنگ هزینهٔ یک فیلتر را دارند.
- **حذفِ بازه‌ها با تکه‌تکه کردن و به هم چسباندن** (نه شمارشِ فریم) ⇒ ویدیوی گوشی (نرخِ فریمِ متغیر) با صدا هم‌زمان می‌ماند.
- **هم‌سطح‌سازیِ دو پاسه و خطی:** پاسِ اول بلندی را می‌سنجد، پاسِ دوم دقیق می‌رساند (آزمون: ‎−۴۱٫۴ ⇐ ‎−۱۶٫۰ LUFS).
- **تثبیتِ دو پاسه** (vidstab): تحلیلِ لرزش نگه داشته می‌شود تا تغییرِ رنگ دوباره تحلیل نخواهد.
- **کاهشِ نویز** با کفِ نویزِ سنجیده‌شدهٔ همان ضبط تنظیم می‌شود (آزمون: کفِ نویز ‎−۴۰ ⇐ ‎−۵۸ dBFS).

## ۳. API

| مسیر | کار |
|---|---|
| `GET /api/health` | FFmpeg، دیسکِ آزاد، هوشِ مصنوعی |
| `GET /api/tools` · `GET /api/tools/openai` | ابزارها و پریست‌ها · قالبِ function calling (۵ تابع) |
| `GET /api/videos` · `POST /api/videos?name=` · `GET`/`DELETE /api/videos/{id}` | کتابخانه (بارگذاری جریانی: بدنهٔ خام یا فیلدِ `file`) |
| `GET /api/videos/{id}/thumb` · `/strip/{i}` · `/waveform` · `/source` | عکسِ کوچک، نوارِ فریم‌ها، موجِ صدا، فایلِ اصلی |
| `GET`/`PUT /api/videos/{id}/recipe` | نسخهٔ ویرایش |
| `POST /api/videos/{id}/frame?t=&max=&original=1` | بدنه: نسخه ⇒ فریمِ JPEG (~۱۰۰ میلی‌ثانیه) |
| `POST /api/videos/{id}/preview?start=&dur=` | ⇒ کار ⇒ MP4ِ کوچک |
| `POST /api/videos/{id}/export` | بدنه: نسخه (خالی ⇒ ذخیره‌شده) ⇒ کار |
| `GET /api/jobs/{id}` · `/api/jobs/{id}/file?download=1` · `DELETE /api/jobs/{id}` | پیشرفت · فایل · لغو |
| `GET /api/videos/{id}/analyze` · `POST /api/videos/{id}/auto` | سنجش · تنظیمِ خودکار |
| `POST /api/videos/{id}/pauses?db=&min=` | مکث‌ها ⇒ بازه‌های پیشنهادی (بی `db` ⇒ آستانهٔ خودکار) |
| `GET /api/videos/{id}/sheet?edited=1` | تصویرِ ۲×۲ از چهار لحظه |
| `POST /api/videos/{id}/ai-edit` | بدنه: `{ "goal": "...", "recipe": {...} }` |
| `GET /api/luts` · `POST /api/luts?name=` | LUTهای .cube |

خروجی و پیش‌نمایش «کار» (job) هستند: شناسه برمی‌گردد، پیشرفت را بپرسید، فایل را بگیرید. خروجی‌ها یکی‌یکی و با اولویتِ پایین ساخته می‌شوند تا کامپیوتر کُند نشود. خطا همیشه `{"error":"پیامِ فارسی"}`: ۴۰۰ ورودیِ بد، ۴۰۴ نیست، ۵۰۰ خطای FFmpeg، ۵۰۳ FFmpeg نیست یا دیسک پر است.

در Command Prompt (cmd):

```bat
set B=http://localhost:5680
curl -X POST -H "Content-Type: video/mp4" --data-binary @clip.mp4 "%B%/api/videos?name=clip.mp4"
rem    ⇐ {"id":"260929-093447-3f246b", ...}
set ID=260929-093447-3f246b
curl -X PUT -H "Content-Type: application/json" -d "{\"preset\":\"reels\",\"adjust\":{\"noise\":40}}" %B%/api/videos/%ID%/recipe
curl -X POST %B%/api/videos/%ID%/export
rem    ⇐ {"id":"18c45cdf79","state":"queued",...}  ⇒ تا state=done بپرسید:
curl %B%/api/jobs/18c45cdf79
curl -o out.mp4 "%B%/api/jobs/18c45cdf79/file?download=1"
```

```python
import requests, time
B = "http://localhost:5680"
v = requests.post(f"{B}/api/videos", params={"name": "clip.mp4"}, data=open("clip.mp4", "rb")).json()
requests.put(f"{B}/api/videos/{v['id']}/recipe", json={"preset": "reels", "audio": {"normalize": -14}})
job = requests.post(f"{B}/api/videos/{v['id']}/export").json()
while (job := requests.get(f"{B}/api/jobs/{job['id']}").json())["state"] not in ("done", "failed", "cancelled"):
    time.sleep(1)
open("reels.mp4", "wb").write(requests.get(f"{B}/api/jobs/{job['id']}/file").content)
```

## ۵. سرعت و حافظه (اندازه‌گیری‌شده روی i5-4590 بی کارتِ گرافیک، ۸GB)

| کار | زمان |
|---|---|
| فریمِ ویرایش‌شده (۶۴۰×۳۶۰) | ~۱۰۰ میلی‌ثانیه |
| پیش‌نمایشِ متحرکِ ۲ ثانیه | ~۰٫۳ ثانیه |
| خروجیِ ریلزِ ۶ ثانیه (۴۸۰×۸۵۴، زمینهٔ محو، هم‌سطح‌سازیِ دو پاسه، کاهشِ نویز، وزوزِ برق، لوک) | ~۴ ثانیه |
| ۱۲ خروجیِ آزمون (۳۲۰×۱۸۰، ۴ ثانیه) | ~۹ ثانیه |
| کلِ آزمونِ نصب (۶۵ وارسی) | ~۳۰ ثانیه، اوجِ حافظه ~۱۵۰MB |

خروجیِ ۱۰۸۰p روی این کامپیوتر عمداً آزموده نشده (آزمون‌ها سبک‌اند تا سیستم سنگین نشود)؛ زمانش به طولِ فیلم، نویزگیری، تثبیت و کدک بستگی دارد و H.265 از H.264 کُندتر است. FFmpeg با اولویتِ پایین اجرا می‌شود و حافظهٔ کمی می‌گیرد، پس کامپیوتر قفل نمی‌شود، فقط پردازنده مشغول است. سرورِ با کارتِ گرافیکِ NVIDIA می‌تواند با NVENC چند برابر سریع‌تر کدگذاری کند (هنوز فعال نشده).

## ۷. محدودیت‌ها و گامِ بعد

- یک کلیپ در هر نسخه (خطِ زمانِ چندکلیپی، ترنزیشن بینِ کلیپ‌ها، متن و زیرنویس در برنامه‌اند).
- تثبیت و آهسته‌نمایشِ نرم فقط در «▶ پخش» و خروجی دیده می‌شوند (به فریم‌های پشتِ سرِ هم نیاز دارند).
- روی ویدیوی خیلی طولانی «سنجش» و «یافتنِ مکث‌ها» کلِ صدا را یک بار می‌خوانند (برای یک ساعت صدا چند ده ثانیه).
- در برنامه (FEATURES.md بخشِ ۴): **زیرنویسِ خودکارِ فارسی** (FFmpegِ این کامپیوتر Whisper دارد + ASRِ پروژهٔ صدا)، تطبیقِ رنگِ دو کلیپ، ترمیمِ رولینگ‌شاتر، کمپرسورِ چندباندی، کاهشِ طنین، کدگذاریِ سخت‌افزاری.
