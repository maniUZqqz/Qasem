# UpMarket AI Studio — پنل Flask برای ComfyUI

این پروژه یک رابط محلی برای اجرای workflowهای ComfyUI است. Flask درخواست‌ها را مدیریت می‌کند؛ تولید واقعی توسط ComfyUI و مدل‌های نصب‌شده روی سیستم انجام می‌شود.

## تغییرات این نسخه

- انتخاب چند پروفایل جداگانه برای تصویر، ویرایش تصویر و ویدئو؛ ورودی‌های فرم با پروفایل انتخاب‌شده تغییر می‌کنند.
- پروفایل‌های تصویر FLUX: متعادل 1024، عمودی 768×1024، سریع‌تر 768.
- پروفایل‌های ویرایش: تغییر متعادل و حفظ بیشتر تصویر اصلی.
- پروفایل‌های Wan 2.2: کلیپ کوتاه 17 فریم و کلیپ طولانی‌تر 33 فریم در 480p.
- تنظیم اولیه متناسب با RTX 3060 12GB: FLUX با 24 گام و FluxGuidance 3.5؛ ویدئو با 832×480، 8 گام و 17 فریم به‌صورت پیش‌فرض.
- REST API نسخه‌دار با API key برای اتصال برنامه‌های دیگر.

> **مهم:** workflowهای موجود از روی فایل‌های قبلی تنظیم شده‌اند و روی نصب واقعی ComfyUI تو از راه دور تست نشده‌اند. نام loaderها و نودها به نسخه ComfyUI و محل نصب مدل‌ها وابسته است. اگر ComfyUI در ترمینال خطا بدهد، اول باید همان خطا رفع شود. تنظیمات کیفیت نقطه شروع معقول‌اند، نه تضمین کیفیت ثابت.

## اجرا در Windows

1. ZIP را در یک مسیر ساده استخراج کن.
2. مسیر `COMFY_BAT` در `START_UPMARKET.bat` را با محل واقعی `run_nvidia_gpu.bat` تطبیق بده.
3. `START_UPMARKET.bat` را اجرا کن. این فایل ComfyUI را بررسی/اجرا می‌کند و سپس پنل را بالا می‌آورد.
4. پنل: `http://127.0.0.1:5000`
5. ComfyUI: `http://127.0.0.1:8188`

## انتخاب workflow و تغییر کیفیت

در صفحه اصلی نوع خروجی و بعد پروفایل را انتخاب کن. کنترل‌هایی که نمایش داده می‌شوند متعلق به همان پروفایل‌اند؛ مثلاً فریم‌های ویدئو در پروفایل تصویر نمایش داده نمی‌شوند.

فایل `profiles.json` تعریف پروفایل‌ها را نگه می‌دارد. هر پروفایل شامل این موارد است:

- `id`, `kind`, `label`, `description`
- `file`: فایل API workflow در پوشه `workflows`
- `controls`: فیلدهای قابل نمایش در UI
- `targets`: فهرست `[node_id, input_name]` برای اعمال مقدار هر کنترل به نود واقعی

برای اضافه‌کردن workflow کاملاً جدید، آن را در ComfyUI باز کن و از **Save (API Format)** خروجی JSON بگیر. فایل را داخل `workflows/` قرار بده و یک پروفایل به `profiles.json` اضافه کن. شناسه نود و نام ورودی‌ها را با JSON واقعی تطبیق بده. آپلود از صفحه تنظیمات فایل را برای پروفایل‌های همان نوع انتخاب می‌کند، اما لازم است `targets` را با نودهای فایل جدید تطبیق بدهی.

### کیفیت و محدودیت سخت‌افزار

- برای عکس تبلیغاتی، پروفایل متعادل 1024 نقطه شروع است. اگر VRAM پر شد، پروفایل سریع‌تر یا 768 را امتحان کن.
- برای ویرایش، مقدار `denoise` کمتر معمولاً تغییرات کمتری نسبت به عکس اصلی می‌دهد؛ مقدار بالاتر اجازه تغییر بیشتری می‌دهد.
- برای Wan 2.2 روی RTX 3060 12GB، با 17 فریم شروع کن. 33 فریم حرکت طولانی‌تری می‌دهد اما حافظه و زمان بیشتری مصرف می‌کند. اگر خطای CUDA out-of-memory دیدی، عرض/ارتفاع یا تعداد فریم را کاهش بده.
- وضوح بیشتر یا steps بیشتر همیشه به‌تنهایی تصویر را بهتر نمی‌کند؛ پرامپت، مدل دقیق، loader درست، LoRA سازگار و ساختار workflow هم تعیین‌کننده‌اند.
- ویدئوهای 17 فریمی با 16fps تقریباً 1 ثانیه‌اند؛ 33 فریم تقریباً 2 ثانیه است. این پروفایل‌ها برای تست تبلیغ کوتاه‌اند، نه کلیپ طولانی.

## REST API

کلید API در `config.json` ذخیره می‌شود و از صفحه **تنظیمات و API** قابل مشاهده/کپی است. می‌توانی با انتخاب «عوض کردن کلید API» آن را rotate کنی. برای امنیت، کلید را در فرانت‌اند عمومی قرار نده.

هدر احراز هویت یکی از این دو باشد:

```http
X-API-Key: YOUR_API_KEY
```

یا:

```http
Authorization: Bearer YOUR_API_KEY
```

### Endpointها

| متد | مسیر | توضیح |
|---|---|---|
| `GET` | `/api/v1/status` | وضعیت اتصال به ComfyUI |
| `GET` | `/api/v1/workflows` | پروفایل‌ها، مقادیر پیش‌فرض و کنترل‌هایشان |
| `POST` | `/api/v1/generate` | ثبت درخواست تولید |
| `GET` | `/api/v1/jobs` | فهرست jobها |
| `GET` | `/api/v1/jobs/<prompt_id>` | وضعیت یک job |

### مثال: دریافت فهرست پروفایل‌ها

```bash
curl http://127.0.0.1:5000/api/v1/workflows \
  -H "X-API-Key: YOUR_API_KEY"
```

### مثال: تولید تصویر

```bash
curl -X POST http://127.0.0.1:5000/api/v1/generate \
  -H "X-API-Key: YOUR_API_KEY" \
  -F "kind=image" \
  -F "profile_id=flux-product-balanced" \
  -F "prompt=Premium product photo, realistic materials, studio lighting" \
  -F "width=1024" -F "height=1024" -F "steps=24" \
  -F "guidance=3.5" -F "seed=-1"
```

### مثال: تولید ویدئو از عکس

```bash
curl -X POST http://127.0.0.1:5000/api/v1/generate \
  -H "X-API-Key: YOUR_API_KEY" \
  -F "kind=video" \
  -F "profile_id=wan22-480p-short" \
  -F "prompt=The product slowly rotates on a studio table, natural camera movement" \
  -F "width=832" -F "height=480" -F "length=17" -F "steps=8" -F "seed=-1" \
  -F "image=@product.png"
```

`kind` برای تصویر `image`، ویرایش `edit` و ویدئو `video` است. برای `edit` و `video` فایل عکس با فیلد `image` اجباری است. برای مقدارهای مجاز کنترل‌ها، اول `/api/v1/workflows` را بخوان.

پاسخ ثبت job شامل `prompt_id` است. سپس `/api/v1/jobs/<prompt_id>` را poll کن تا `status` به `completed` یا `error` برسد.

### امنیت

- به‌طور پیش‌فرض Flask فقط روی `127.0.0.1` گوش می‌دهد؛ API برای استفاده محلی است.
- API را بدون reverse proxy امن، HTTPS، محدودیت شبکه و حفاظت مناسب روی اینترنت منتشر نکن.
- اگر `UPMARKET_API_KEY` در environment تنظیم شده باشد، همان مقدار به‌جای کلید `config.json` استفاده می‌شود.
