# InstAI روی رایانهٔ GPUدار: خودکار به‌روز، روشن و آزمایش‌شده

InstAI (استودیوی انیمیشن و داستان؛ `github.com/maniUZqqz/Instai`، شاخهٔ `main`) روی همان رایانه‌ای کار می‌کند که پردازشگر NMarketing روی آن است
(`C:\Users\QQz\Desktop\Instai-main\V2\Instai-main`). پوشهٔ فعلی از یک «Download ZIP» قدیمی مانده و `START.bat`ِ قدیمیِ آن به‌روزرسانی بلد نیست؛ پس هر اصلاحی که روی
GitHub می‌رفت به آن نمی‌رسید مگر این‌که کسی ZIP تازه را دستی روی پوشه کپی کند. از عامل نسخهٔ پردازشگر که `processing/instai_jobs.py` را دارد، دیگر لازم نیست.

## عامل خودش چه می‌کند (هر دو دقیقه یک نگاه؛ پرسش از GitHub حداکثر نیم‌ساعت یک بار)

1. پوشهٔ InstAI را پیدا می‌کند (متغیر `NM_INSTAI_DIR`، پوشهٔ یادآوری‌شده، یا پوشه‌ای که اسمش `instai` دارد روی Desktop / پوشهٔ کاربر / ریشهٔ دیسک‌ها تا سه سطح؛
   باید `manage.py` و `instai\settings.py` و `VERSION` داشته باشد).
2. `VERSION` شاخهٔ `main` را از GitHub می‌خواند (فایل خام؛ آینهٔ CDN راه دوم) و حالت خودِ InstAI را می‌بیند: نسخه، آیا `START.bat` به‌روزرسان دارد، آیا سرور جواب می‌دهد
   (`/api/health`)، و گزارش خودآزمونِ InstAI (`data\selftest\pc.json`).
3. اگر پوشه خودش را به‌روز نمی‌کند (`START.bat` بدون `self_update.py`) یا نسخهٔ GitHub تازه‌تر است **و InstAI روشن نیست**، همان به‌روزرسانِ خودِ InstAI
   (`scripts\self_update.py`) را اجرا می‌کند؛ پوشهٔ قدیمی آن فایل را ندارد، پس فقط همین یک فایل از GitHub گرفته و وارسی می‌شود (می‌گوید «InstAI self-update» و کامپایل می‌شود).
   این به‌روزرسان `data`، `.env`، `models`، `tools`، `.venv` و `node_modules` را هرگز دست نمی‌زند، هر فایلی را که عوض کند اول پشتیبان می‌گیرد و هرگز به نسخهٔ پایین‌تر برنمی‌گردد.
4. بعد از به‌روزرسانی (و یک بار وقتی خودِ گره بالا می‌آید و InstAI اصلاً روشن نیست) `START.bat` را بدون مرورگر و بدون مکث اجرا می‌کند؛ بارِ اول InstAI بسته‌های خودش را
   نصب و Remotion را در پس‌زمینه آماده می‌کند. بعد از `STOP.bat` دوباره روشنش نمی‌کند (تا بالا آمدنِ بعدیِ گره).
5. همهٔ این‌ها را در ضربان قلب گزارش می‌کند (`caps["instai"]`)؛ آزمونِ خودکارِ گره (`instai`، اختیاری) همان را می‌سنجد: پیدا نشدن = «ردشده» نه خطا؛ در حال
   به‌روزرسانی/روشن شدن = «منتظر»؛ شکست = خطا با پیام خودِ به‌روزرسان؛ روشن و به‌روز = قبول، با خلاصهٔ آزمون خودکارِ InstAI (چند سالم، چند منتظر).

## هرگز

InstAI روشن را دست نمی‌زند (به‌روزرسانی منتظر می‌ماند تا خاموش شود)، داده و `.env` و مدل‌ها را رونویسی یا پاک نمی‌کند، چیزی به جز دو خواندنِ GitHub نمی‌فرستد و
اگر چیزی خراب شود عامل را نمی‌ایستاند (هر خطا یک خط در گزارش است).

## کلیدها (محیط عامل)

`NM_INSTAI_SYNC=0` (فقط گزارش؛ نه به‌روزرسانی نه روشن کردن) · `NM_INSTAI_START=0` (به‌روز می‌کند ولی روشن نمی‌کند) · `NM_INSTAI_DIR=<پوشه>` · `NM_INSTAI_REPO` / `NM_INSTAI_BRANCH`.
دیدنِ حالت از خط فرمان: `python instai_jobs.py` (فقط گزارش) یا `python instai_jobs.py --apply`.
