# سی سبکِ تازهٔ موشن از کتابخانهٔ هنریِ InstAI

> مالک (۱۴۰۵/۰۸/۲۳): «قابلیت‌ها و کدهایی که برای NM هست و به درد InstAI می‌خوره (و برعکس) ببر … موشن‌گرافی هر دو طرف، ولی مقداری برای هر طرف کاستوم باشه».
> این سند طرفِ **InstAI ⇒ NM** است (طرفِ برگشت، NM ⇒ InstAI، کارِ جدایی است).

## ۱) خلاصه

- NM تا امروز **۶۶** سبکِ موشن داشت (فهرستِ نام‌هایی که مالک گفته بود)؛ InstAI **۱۱۶** سبکِ هنری دارد.
- هر سبکِ InstAI را با فهرستِ ۶۶ سبکِ NM مقایسه کردیم؛ **سی** سبک که NM نداشت به «ردیفِ سبک» در `catalog.py` تبدیل شد ⇒ **۹۶ سبک**.
- برای فروشگاه‌ها «تنوعِ ظاهر» یعنی ریل‌هایی که شبیهِ هم نمی‌شوند. هر سبک فقط یک ردیفِ داده است و موتورِ Remotion بدونِ کدِ ویدیوی تازه آن را می‌خواند؛ فقط **هشت «نوعِ» تازه** (۷ پس‌زمینه + ۱ تزئین) به موتور اضافه شد، چون NM برای آن سطح‌ها همتا نداشت.
- یک **گروهِ تازه** در گالری: «نقاشی و چاپِ دستی» (۱۲ سبک). گروه‌هایِ دیگر همان‌اند (کارتونی، دست‌ساز، گرافیک، دیجیتال، سه‌بعدی، سینمایی).
- هر سبکِ تازه یک خطِ «مناسبِ …» دارد (`fits`) که در گالری زیرِ توضیحِ سبک دیده می‌شود: چه نوع فروشگاهی از آن بیشتر سود می‌برد.
- **هیچ وابستگیِ اجرایی به InstAI نیست.** ۱۱۶ سبکِ InstAI یک عکسِ ثابت است (`backend/tools/instai_looks/snapshot.json`)؛ NMarketing هرگز InstAI را import نمی‌کند.

## ۲) مبدأ و مجوز

| مورد | توضیح |
|---|---|
| مبدأ | InstAI: `instai/styles/builtin_styles.py` (پالت، رویکردِ حرکت، سرعتِ پوز، motif)، `remotion/src/kit/motion.ts` (شخصیتِ حرکت)، `kit/theme.ts` (نقشِ رنگ‌ها)، `kit/Look.tsx` (سطحِ کشیده‌شدهٔ هر motif) — نسخهٔ `2f8aa90` (v0.14.0) |
| یادداشتِ SOURCE | بالایِ هر فایلِ برگرفته: `SOURCE: ported from InstAI:<path> @ 2f8aa90, adapted for NMarketing store ads` (`looks.tsx`، `catalog_looks.py`، `gen_instai_looks.py`، `instai_looks/*.py`) |
| نام‌ها | هیچ نامِ استودیو، برند، سازنده یا هنرمندی در شناسه، نامِ فارسی/انگلیسی، توضیح، `fits` یا برچسبِ سبک‌هایِ تازه نیست (فهرستِ ممنوعِ InstAI بدونِ تغییر در `tests_looks.py` اجرا می‌شود). «الهام‌گرفته از …» هم برای این سی سبک گذاشته نشد. |
| دارایی | هیچ تصویر، قلم یا فایلی کپی نشد: همهٔ سطح‌ها با CSS/SVG در کد کشیده می‌شوند. |
| قلم‌ها | فقط از مجموعهٔ قلم‌هایِ خودِ NM (SIL Open Font License 1.1 و Apache-2.0 — جدولِ مجوزهایِ `README-fa.md` بخشِ ۱۸)؛ قلمِ تازه نیامده است. |
| مجوزِ کد | هر دو مخزن از آنِ یک مالک‌اند؛ کدِ سطح‌ها برای موتورِ NM دوباره نوشته شد (واحدها، پالتِ ۸رنگ، ساعتِ استاپ‌موشنِ NM)، نه کپیِ کلمه‌به‌کلمه. |

## ۳) تفاوتِ ۱۱۶ سبکِ InstAI با ۶۶ سبکِ NM

این جدول را `python backend/tools/gen_instai_looks.py --update-doc docs/motion/looks-from-instai-fa.md` از روی `catalog.py` و عکسِ InstAI می‌سازد (دستی نوشته نشده؛ آزمونِ `tests_looks` تازه‌بودنش را می‌سنجد). چهار وضعیت:

- **NM دارد:** همان سطح در NM هست (ستونِ «سبکِ NM»).
- **نزدیک دارد:** سبکِ نزدیکی هست و ردیفِ دوم فقط تعویضِ رنگ می‌شد (مثلاً چند سبکِ «انیمه» که فقط در طراحیِ شخصیت فرق دارند، نه در سطحِ ویدیو).
- **تازه افزوده شد:** یکی از سی سبکِ این کار.
- **نمی‌شود:** با کد کشیدنی نیست (فیلمِ زندهٔ مستند، روتوسکوپ)؛ جعل نشد.

## ۸) دوباره‌ساختن و افزودنِ سبکِ بعدی

```bash
# ساختِ ردیف‌ها از عکسِ InstAI + دستورها (تکرارپذیر؛ --check فقط می‌سنجد)
python backend/tools/gen_instai_looks.py [--check]
# جدول‌هایِ این سند و جدولِ README
python backend/tools/gen_instai_looks.py --update-doc docs/motion/looks-from-instai-fa.md
python motion/tools/gen_style_table.py --update docs/motion/README-fa.md
# فایلِ موتور (styles.generated.json)، بسته و ورق‌هایِ نمونه
cd backend && ../venv/bin/python manage.py motion_build --only catalog,shell
../venv/bin/python backend/tools/looks_sheet.py --bundle <data>/motion/bundle --out /root/stage/looks-sheet
# کنترلِ کیفیتِ واقعی (qa.py) روی چند سبک؛ سنگین است ⇒ زیرِ flock؛ بدونِ این دو متغیر آزمون بی‌صدا رد می‌شود (تنظیماتِ `manage.py test` بسته است)
NM_DATA_DIR=<دادهٔ سایت> MEDIA_ROOT=<رسانهٔ سایت> NM_LOOKS_IDS=manga-ink,tilt-shift NM_LOOKS_OUT=/root/stage/looks-qa ../venv/bin/python -X utf8 manage.py test apps.motion.tests_looks_e2e
```

برایِ سبکِ تازه از InstAI: ردیفِ آن را در `snapshot.json` بگذارید (یا عکسِ تازه بگیرید)، یک دستور در `recipes.py` بنویسید، و اگر حرکتش رویکردِ تازه‌ای است ردیفی به `MOTION` در `mapping.py` اضافه کنید. آزمونِ `tests_looks` راهنمای خطاست: یک سبکِ InstAI که هیچ‌جا ثبت نشده، یک motif که کسی دربارهٔ آن تصمیم نگرفته، یا پالتی که خوانا نیست، آزمون را می‌شکند.

## ۹) محدودیت‌ها

- سبک‌هایِ «شخصیت‌محور» یا «فیلمِ زنده» (مستند، روتوسکوپ) را با کد نمی‌شود کشید؛ در جدولِ بالا «نمی‌شود» نوشته شده و NM در «ادیتورِ ویدیو» از فیلمِ خودِ فروشگاه کار می‌کند.
- این سبک‌ها ظاهرِ سطح و حرکت را می‌دهند، نه تصویرِ شخصیت یا محصول؛ عکسِ محصول را فروشگاه می‌دهد.
- حرکتِ «روی ۸» در بعضی سبک‌ها عمداً پله‌پله است؛ برای ریلِ روان، شدتِ حرکت یا سبکِ دیگری انتخاب شود.
- سبک‌هایِ نقاشی‌وار (ورودِ آرامِ `blur`، `bloom`، `float`) واژه‌ها را نرم و آهسته می‌آورند؛ در نمونه‌ایِ ۳٫۵ ثانیه‌ای با زیرنویسِ ۱۱ کلمه‌ای، واژهٔ آخر تا نزدیکِ پایانِ صحنه هنوز در حالِ جا افتادن است (در ورقِ نمونه «دقیقه» کمی محو دیده می‌شود). `qa.py` این را خطا نمی‌داند و برای متنِ کوتاه‌تر یا صحنهٔ بلندتر پیش نمی‌آید.
- «ناحیهٔ امنِ پلتفرم» در ۹:۱۶ برای متنِ پهن (زیرنویسِ عنوان، شعارِ دعوت به اقدام) هشدار می‌دهد؛ این هشدار در سبک‌هایِ قدیمیِ NM هم هست و با «ادیتورِ ویدیو» یا کوچک‌کردنِ متن برطرف می‌شود. پس‌زمینه‌هایِ سبک‌هایِ تازه هرگز متن نمی‌کشند.
