REST API

برای اتصال UpMarket یا اپلیکیشن‌های دیگر، از API نسخه‌دار استفاده کن. کلید زیر مثل رمز عبور است؛ آن را عمومی نکن.

مسیرها

  • GET /api/v1/status — وضعیت ComfyUI
  • GET /api/v1/workflows — فهرست پروفایل‌ها و کنترل‌های هرکدام
  • POST /api/v1/generate — ثبت درخواست تولید
  • GET /api/v1/jobs — فهرست کارها
  • GET /api/v1/jobs/<prompt_id> — وضعیت یک کار

احراز هویت: هدر X-API-Key: YOUR_KEY یا Authorization: Bearer YOUR_KEY.

برای درخواست‌های دارای عکس، از multipart/form-data با فیلدهای kind، profile_id، prompt، negative_prompt و فایل image استفاده کن. کنترل‌های هر پروفایل در GET /api/v1/workflows آمده‌اند.

curl -X GET http://127.0.0.1:5000/api/v1/workflows \
  -H "X-API-Key: YOUR_KEY"
curl -X POST http://127.0.0.1:5000/api/v1/generate \
  -H "X-API-Key: YOUR_KEY" \
  -F "kind=image" -F "profile_id=flux-product-balanced" \
  -F "prompt=Premium product photo, studio lighting" \
  -F "width=1024" -F "height=1024" -F "steps=24" -F "guidance=3.5" -F "seed=-1"

این API به‌صورت پیش‌فرض روی localhost است. برای استفاده از سیستم دیگر، باید آدرس bind و فایروال را آگاهانه تنظیم کنی؛ API را بدون کلید و بدون محدودیت شبکه در اینترنت منتشر نکن.

Workflow ویدئو

آپلود workflow از ComfyUI

برای هر نوع خروجی یک فایل جداگانه API JSON بساز.

چطور Node ID را پیدا کنم؟

  1. Workflow را در ComfyUI باز کن.
  2. از منوی ذخیره، Save (API Format) را انتخاب کن؛ JSON معمولی گرافیکال کافی نیست.
  3. JSON را با Notepad باز کن. کلیدهای سطح اول مثل "12"، ID نود هستند.
  4. نود متن را پیدا کن؛ داخل آن "class_type" و "inputs" را ببین. برای متن معمولاً ورودی text است، اما به نوع نود وابسته است.
  5. برای تصویر، نود Load Image و ورودی image را پیدا کن. برای ویدئو، تصویر مرجع را به همان نود وصل کن.
  6. فیلدهای این صفحه را با IDها و نام ورودی‌های واقعی workflow پر کن.

اگر در یک workflow پرامپت مثبت/منفی یا seed چند نود دارد، باید نودی را تنظیم کنی که ورودی متنی/seed واقعاً در مسیر تولید استفاده می‌شود. اسم و IDها بین workflowها فرق می‌کند.
