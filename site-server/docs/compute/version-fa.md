# نسخهٔ نرم‌افزار (v2.60)

گوشهٔ همهٔ صفحه‌ها یک نشانِ کوچک مثل **v2.60** دیده می‌شود: در پنل (حتی صفحهٔ ورود و ویرایشگرهای عکس و ویدیو)، در ادمین (کنارِ نامِ سایت) و در پایینِ سایتِ عمومی. با زدن روی آن صفحهٔ «چه چیزی تازه است» باز می‌شود. اگر موس را رویش نگه دارید، تاریخِ ساخت و کامیت را می‌نویسد.

## شماره از کجا می‌آید

فقط یک جا: فایل `VERSION` در ریشهٔ پروژه (`/var/www/NM/upmarket/VERSION`)، یک خط، مثل `2.60`. قالبش `بزرگ.کوچک` است و بخشِ کوچک همیشه دو رقم دارد: بعد از `2.99` می‌آید `3.00`.

کنارش دو فایل دیگر هست:

| فایل | چیست |
|---|---|
| `build.json` | `{"version", "built_at", "commit"}` — خودکار نوشته می‌شود، دستی ویرایش نکنید |
| `CHANGELOG-fa.md` | فهرستِ «چه چیزی تازه است» به فارسی؛ هر نسخه یک تیتر `## v2.60 — ۱۴۰۵/۰۸/۱۶` و زیرش چند خطِ `- ...` |

## شماره چطور بالا می‌رود

با `deploy/nm/bump-version.sh` (۲٫۶۰ ⇐ ۲٫۶۱):

- **خودکار، پس از نصب:** آخرِ `install.sh` (`nm.sh update`).
- **خودکار، پیش از هر ارسالِ خودکار به گیت‌هاب:** `git-autopush.sh` (هر ۶ ساعت). اگر از آخرین بار هیچ کدی عوض نشده باشد، شماره بالا نمی‌رود.
- **دستی:** `nm.sh bump` (همین حالا یک شماره بالا ببر)، `nm.sh bump --if-changed` (فقط اگر چیزی عوض شده)، `nm.sh version` (فقط نشان بده).

«عوض شده» یعنی هر فایلِ کد، قالب یا اسکریپت (نه داده، لاگ، بیلد، `.env` و نه فایل‌های `*.bak*`). اولین اجرا فقط «خط‌مبنا» را ثبت می‌کند و شماره را عوض نمی‌کند. اسکریپت هرگز استقرار یا پشتیبان‌گیری را نمی‌خواباند (همیشه با کدِ ۰ برمی‌گردد).

برای نوشتنِ «چه چیزی تازه است»: پیش از (یا همراهِ) bump، یک تیترِ تازه با شمارهٔ بعدی بالای `CHANGELOG-fa.md` بگذارید.

## نشانی‌ها

| نشانی | کار |
|---|---|
| `GET /api/v1/version/` | `{"version","built_at","commit","name"}` — عمومی، بی‌ورود، از حافظه (با تغییرِ فایل تازه می‌شود) |
| `GET /api/v1/version/changelog/` | `{"name","current","entries":[{"version","date","summary","items":[...]}]}` — فایلِ خراب ⇒ فهرستِ خالی، نه خطا |
| `/panel/changelog` | صفحهٔ «چه چیزی تازه است» (بی‌ورود) |

سایتِ عمومی (Next.js) نسخه را از همان API می‌خواند و هر ۲ دقیقه تازه می‌کند؛ اگر API نباشد، نشان نمایش داده نمی‌شود و صفحه سالم می‌ماند.
