# ویرایشگرِ عکس (PersianAiKit.Photo)

همهٔ ویرایش‌هایی که عکس را بهتر می‌کنند — نور و رنگ، منحنی، وضوح و مه، شارپ و نویزگیری، برش و صاف کردن، ترمیمِ لکه، فیلترهای آماده، حذفِ پس‌زمینه، بزرگ‌نمایی و خروجیِ فروشگاهی — در **دو قالب با یک موتور**:

1. **فوتوشاپِ وب** — ویرایشگرِ فارسی در مرورگر (`http://localhost:5670`): لغزنده‌ها، منحنی، هیستوگرام، برش، قلمِ روتوش، قلمِ ماسک، قبل/بعد، برگرداندن.
2. **ابزار برای هوشِ مصنوعیِ بینا** — همان ابزارها به شکلِ یک «نسخهٔ ویرایش» (JSON). هوشِ مصنوعی عکسِ کوچک را می‌بیند و فقط نسخه را می‌نویسد؛ ویرایش را موتورِ خودمان روی دستگاه انجام می‌دهد ⇒ **ارزان** (چند هزار توکن برای هر عکس، با مدل‌های رایگان صفر). جزئیات: **[AI.md](AI.md)**.

همه‌چیز آفلاین و روی CPU اجرا می‌شود (.NET 8 + OpenCV). هوشِ مصنوعی فقط برای «ویرایش با هوشِ مصنوعی» به اینترنت (یا مدلِ محلی) نیاز دارد؛ بی آن، «خودکار»ِ رایگان کار می‌کند.

```
project Photo\
├─ Run-Server.bat          ← ویرایشگرِ وب + API  (http://localhost:5670 — مرورگر خودش باز می‌شود)
├─ Run-SelfTest.bat        ← آزمونِ نصب (سبک: زیرِ ۱GB حافظه، ~۱۵ ثانیه)
├─ README.md  AI.md  FEATURES.md (فهرستِ کاملِ ابزارها؛ از روی کد ساخته می‌شود)
├─ src\PersianAiKit.Photo\          موتور: Recipe، ToolCatalog، Presets، Engine\*، Ai\*
├─ src\PersianAiKit.Photo.Server\   سرویس + wwwroot (صفحهٔ وب)
├─ src\PersianAiKit.Photo.SelfTest\ آزمون
├─ models\    background\birefnet-lite.onnx (اختیاری، سنگین)   upscale\realesr-general-x4v3.onnx
├─ samples\   عکس‌های نمونه (مالکیتِ عمومی) + ماسکِ مرجعِ BiRefNet برای آزمون
├─ research\  ایده‌ها و فهرستِ ۴۶۹ قابلیتِ فتوشاپ (Photoshop_Features_FA.xlsx)
├─ tools\Download-Models.ps1
└─ data\      کتابخانهٔ عکس‌ها (docs\<id>\: اصل، نسخه، ماسک) و خروجیِ آزمون
```

## شروعِ سریع

1. [.NET 8 SDK](https://dotnet.microsoft.com/download) (یا بالاتر).
2. `Run-SelfTest.bat` — همهٔ ابزارها روی عکس‌های ساختگی (جوابِ درست معلوم) و نمونه‌ها؛ آخرش باید «همه درست است ✓» بگوید.
3. `Run-Server.bat` — مرورگر روی `http://localhost:5670` باز می‌شود. عکس را روی صفحه بکشید (یا «باز کردنِ عکس» یا Ctrl+V).

مدل‌ها اختیاری‌اند: همهٔ لغزنده‌ها، فیلترها، خودکار، حذفِ سبکِ پس‌زمینه و صفحهٔ وب **بی هیچ مدلی** کار می‌کنند. اگر پوشهٔ `models` نیست: `powershell -ExecutionPolicy Bypass -File tools\Download-Models.ps1` (فقط بزرگ‌نما، ۵MB) یا با `-Server` (+ مدلِ سنگینِ پس‌زمینه، ۲۲۴MB).

## ۱. فوتوشاپِ وب

| زبانه | چه دارد |
|---|---|
| **تنظیم** | هیستوگرام (با نشانِ سوختگی)، «✦ خودکار»، و ۵۸ لغزنده در گروه‌ها: نور، **منحنی** (RGB و هر کانال)، رنگ، رنگ‌به‌رنگ (HSL در ۸ خانوادهٔ رنگ)، رنگ‌دهیِ سایه/روشنی، سطوح، وضوح و مه، جزئیات، افکت، لنز. دوبار کلیک روی نام = بازنشانی. |
| **فیلتر** | ۱۴ فیلترِ آماده با پیش‌نمایشِ زنده روی همان عکس (روشن و تمیز، پرجلوه، گرم، سرد، سیاه‌وسفید، فیلمیِ مات، سینمایی، پرتره، منظره، غذا، عکسِ فروشگاهی، …). فیلترِ بعدی جای قبلی را می‌گیرد. |
| **برش** | کادر کشیدن روی عکس، نسبت‌ها (آزاد، اصلی، ۱:۱، ۴:۵، ۳:۴، ۴:۳، ۱۶:۹، ۹:۱۶)، چرخش ±۴۵° برای صاف کردنِ افق (بی گوشهٔ خالی)، قرینهٔ افقی/عمودی. |
| **روتوش** | کلیک روی لکه، جوش، خش یا گرد ⇒ از روی اطرافش پر می‌شود. کلیکِ راست روی دایره = حذف. |
| **پس‌زمینه** | حذفِ پس‌زمینه (سبک یا هوشِ مصنوعی)، رنگِ تازه یا شفاف، **بررسیِ لبه روی سیاه/سفید/شطرنجی**، گزارشِ تمیزیِ لبه، تمیزکاریِ خودکار، سایهٔ نرم، **قلمِ اصلاحِ ماسک** (نگه‌دار/پاک‌کن). |
| **خروجی** | JPEG/PNG/WebP، کیفیت، اندازه، **قابِ مربعِ فروشگاه** (کالا وسط با حاشیه)، بزرگ‌نماییِ هوشمندِ ×۲/×۴، شارپِ نهایی، و دکمهٔ «عکسِ فروشگاهی» (زمینهٔ سفید، مربعِ ۲۰۰۰). |
| **هوشِ مصنوعی** | هدف را بنویسید («عکسِ کالا برای فروشگاه با زمینهٔ سفید») ⇒ هوشِ مصنوعی نسخه را می‌سازد؛ مدل، دورها و توکن‌ها نشان داده می‌شود. |

کلیدها: **Ctrl+Z** / **Ctrl+Y** برگرداندن و دوباره (۱۵۰ مرحله) · نگه داشتنِ **`\`** یا دکمهٔ «قبل/بعد» = عکسِ اصل · **Esc** برگشت به «تنظیم». همه‌چیز خودکار ذخیره می‌شود؛ پیوندِ مستقیم: `http://localhost:5670/#doc=<id>&tab=crop`. روی گوشی هم کار می‌کند.

هنگامِ کشیدنِ لغزنده پیش‌نمایشِ سریع (۸۰۰ پیکسل) و بعد از رها کردن پیش‌نمایشِ کامل ساخته می‌شود؛ درخواستِ تازه جای درخواستِ در صف را می‌گیرد، پس صفحه عقب نمی‌ماند.

## ۲. «نسخهٔ ویرایش» (Recipe)

هر ویرایش — از صفحه، از API یا از هوشِ مصنوعی — یک JSON است؛ عکسِ اصلی هرگز عوض نمی‌شود:

```json
{
  "preset": "warm",
  "adjust": { "exposure": 0.4, "shadows": 30, "temperature": -10, "clarity": 15 },
  "curve":  { "rgb": [[0,0],[70,55],[190,210],[255,255]] },
  "crop":   { "x": 0.05, "y": 0, "w": 0.9, "h": 1, "angle": 1.5 },
  "spots":  [ { "x": 0.41, "y": 0.33, "r": 0.01 } ],
  "background": { "remove": true, "method": "auto", "color": "#ffffff", "cleanup": -1, "shadow": 25 },
  "output": { "format": "jpeg", "quality": 92, "longEdge": 2000, "square": true, "padding": 0.06, "upscale": 1 }
}
```

هر چه نیامده = پیش‌فرض (بی‌اثر). کلیدِ ناشناخته دور ریخته و عددِ بیرون از بازه بریده می‌شود — ورودیِ خرابِ هوشِ مصنوعی هم عکس را خراب نمی‌کند. فهرستِ همهٔ کلیدها، بازه‌ها و معادلِ فتوشاپِ هرکدام در **[FEATURES.md](FEATURES.md)** است.

ترتیبِ اجرا مثلِ Camera Raw: ترمیمِ لکه ⇐ تعادلِ سفیدی و نوردهی (فضای خطی) ⇐ مه‌زدایی ⇐ روشنی‌ها/سایه‌ها ⇐ سطوح، سفید/سیاه، کنتراست، منحنی ⇐ بافت/وضوح ⇐ رنگ (HSL، وایبرنس، اشباع، رنگ‌دهی) ⇐ نویزگیری و شارپ ⇐ لنز، چرخش، برش، قرینه ⇐ وینیت و دانه ⇐ پس‌زمینه ⇐ بزرگ‌نمایی، قاب، اندازه ⇐ رنگِ تازه و سایه ⇐ شارپِ نهایی.

## ۳. حذفِ پس‌زمینه

| روش | کی | سرعت و حافظه (i5-4590، ۸GB) |
|---|---|---|
| `quick` — سبک، بی مدل | کالا روی زمینهٔ ساده یا استودیویی: سفید، رنگی، شیب‌دار، با سایهٔ نرم | عکسِ ۹۶۰ پیکسلی ~۰٫۵ ثانیه، چند مگابایت حافظه |
| `ai` — BiRefNet-lite | هر زمینه‌ای (شلوغ، بیرون، آدم) | ~۷۰ ثانیه و **~۶٫۳GB حافظه** روی CPU ⇒ جایش سرورِ پرحافظه یا GPU است |
| `auto` (پیش‌فرض) | زمینهٔ ساده ⇒ سبک؛ وگرنه هوشِ مصنوعی اگر حافظه و مدل باشد؛ وگرنه باز سبک، با هشدار | — |

**نگهبانِ حافظه:** پیش از اجرای BiRefNet حافظهٔ آزاد وارسی می‌شود؛ اگر کمتر از `RequiredMemoryMB` (۶۵۰۰) باشد اجرا نمی‌شود و پیامِ روشن می‌دهد (در صفحه هم نوشته می‌شود) تا کامپیوتر قفل نکند. مدل بعد از هر اجرا از حافظه بیرون می‌رود.

**روشِ سبک چطور کار می‌کند:** رنگِ زمینه از حاشیهٔ عکس به شکلِ یک سطحِ نرم برازش می‌شود (شیبِ نورِ استودیو را هم می‌گیرد) ⇐ نشانه‌های کالا: رنگِ دیگر، روشن‌تر از زمینه، لبهٔ تیز یا خیلی تیره — سایهٔ نرم (فقط تیره‌تر و صاف) نشانه نیست ⇐ جاهایی که لبهٔ کالا دورشان را گرفته (بدنهٔ صافِ فلز) جزوِ کالا، مگر هم‌رنگِ زمینه باشند (سوراخِ واقعی) ⇐ GrabCut لبه را روی مرزِ رنگ می‌نشاند ⇐ لبهٔ نرم با حلِ دقیقِ «رنگِ دیده = α·کالا + (۱−α)·زمینه» در فضای رنگِ جدا از روشنایی (سایه هرگز هالهٔ نیمه‌شفاف نمی‌شود). روی عکسِ نمونهٔ انبردست (کروم روی سفید) ۹۲٪ با ماسکِ BiRefNet هم‌پوشانی دارد؛ روی زمینهٔ شلوغ خودش می‌گوید «مطمئن نیستم».

**وارسیِ لبه روی رنگِ مخالف (ایدهٔ research/idea-store-photos.txt):** کالا روی رنگی گذاشته می‌شود که زمینهٔ قبلی نبوده (سفید بوده ⇒ سیاه) و هر پیکسلِ لبه که به رنگِ زمینهٔ قبلی نزدیک‌تر است تا به داخلِ کالا «هاله» شمرده می‌شود. تمیزکاریِ خودکار ۰، ۲۵، ۵۰، ۷۵ و ۱۰۰ را امتحان می‌کند و **کمترین** مقداری را برمی‌دارد که هاله زیرِ ۳٪ برود (بیشتر از لازم جزئیاتِ لبه را می‌خورد). تمیزکاری: ماسکِ گشاد تنگ می‌شود (فقط کم، هرگز زیاد)، رنگِ زمینه از پیکسل‌های نیمه‌شفاف بیرون کشیده می‌شود. گزارش: `POST /api/docs/{id}/background` ⇒ `edge.score`، `edge.haloPercent`، `edge.tried`. در صفحه: «روی سیاه / روی سفید / شطرنجی» و قلمِ ماسک برای جاهایی که هنوز خوب نیست.

## ۴. API (برای هر برنامه‌ای: PHP، Python، Node، C#، …)

| مسیر | کار |
|---|---|
| `GET /api/health` | وضعیت: مدل‌ها، حافظهٔ آزاد، هوشِ مصنوعی |
| `GET /api/tools` · `GET /api/tools/openai` | همهٔ ابزارها و فیلترها · همان در قالبِ function calling |
| `GET /api/docs` · `POST /api/docs` (عکس) · `GET`/`DELETE /api/docs/{id}` | کتابخانه |
| `GET`/`PUT /api/docs/{id}/recipe` | نسخهٔ ویرایش |
| `POST /api/docs/{id}/render?max=1200` | بدنه: نسخه (خالی ⇒ ذخیره‌شده) ⇒ پیش‌نمایش (JPEG؛ شفاف ⇒ WebP) |
| `POST /api/docs/{id}/export` | فایلِ نهایی در اندازهٔ اصلی |
| `GET /api/docs/{id}/analyze` · `POST /api/docs/{id}/auto` | اندازه‌گیری‌ها · تنظیمِ خودکارِ رایگان |
| `POST /api/docs/{id}/background?method=auto\|quick\|ai&force=1` | ماسک + گزارشِ لبه |
| `GET`/`PUT`/`DELETE /api/docs/{id}/mask` | ماسک (PNGِ خاکستری) |
| `POST /api/docs/{id}/ai-edit` | بدنه: `{ "goal": "...", "recipe": {...} }` ⇒ ویرایش با هوشِ مصنوعی |
| `POST /api/edit?auto=1&recipe=…` | بی‌کتابخانه: عکس ⇒ عکسِ ویرایش‌شده (نسخهٔ به‌کاررفته در سرآیندِ `X-Recipe`) |
| `POST /api/analyze` | بی‌کتابخانه: عکس ⇒ اندازه‌گیری‌ها + پیشنهادِ خودکار |

عکس را خام در بدنه یا در فیلدِ `file`ِ فرم بفرستید (تا ۶۰MB، JPEG/PNG/WebP/BMP/TIFF، تا ۶۰ مگاپیکسل). خطا همیشه `{"error":"پیامِ فارسی"}` است: ۴۰۰ ورودیِ بد، ۴۰۴ عکس نیست، ۵۰۳ مدل یا حافظه نیست.

در Command Prompt (cmd):

```bat
set B=http://localhost:5670
rem یک‌باره: عکسِ فروشگاهی از هر عکسِ کالا (تنظیمِ خودکار + فیلترِ فروشگاهی)
curl -F "file=@kala.jpg" -F "recipe={\"preset\":\"store\"}" -o kala-store.jpg "%B%/api/edit?auto=1"

rem با کتابخانه: ثبت ⇒ نسخه ⇒ خروجی
curl -F "file=@kala.jpg" %B%/api/docs
rem    ⇐ {"id":"260929-081035-cc42c5", ...}
curl -X PUT -H "Content-Type: application/json" -d "{\"preset\":\"clean\",\"background\":{\"remove\":true}}" %B%/api/docs/260929-081035-cc42c5/recipe
curl -X POST -o out.jpg %B%/api/docs/260929-081035-cc42c5/export
```

(در PowerShell 5.1 نقل‌قولِ داخلِ JSON به `curl.exe` نمی‌رسد؛ نسخه را در فایل بگذارید: `-F "recipe=<recipe.json"` و `-d "@recipe.json"`.)

```python
import requests, json
B = "http://localhost:5670"
r = requests.post(f"{B}/api/edit", params={"auto": 1},
                  files={"file": open("kala.jpg", "rb")},
                  data={"recipe": json.dumps({"preset": "store", "output": {"longEdge": 1200}})})
open("kala-store.jpg", "wb").write(r.content)
```

## ۸. محدودیت‌ها و گامِ بعد

- فایلِ RAWِ دوربین نه (JPEG، PNG، WebP، BMP، TIFFِ ۸ و ۱۶ بیتی بله؛ ۱۶ بیتی با دقتِ اعشاری پردازش می‌شود، خروجی ۸ بیتی).
- روشِ سبکِ پس‌زمینه: سایهٔ **تیز** (نورِ مستقیم) ممکن است جزوِ کالا بماند؛ کالای خاکستریِ خیلی روشن روی سفید سخت است ⇒ قلمِ ماسک یا `ai` روی سرور.
- در برنامه (FEATURES.md بخشِ ۴): حذفِ چیزهای بزرگ (LaMa)، رفعِ لبهٔ رنگیِ لنز، صاف کردنِ خودکار (Upright)، HDR و پانوراما، مدلِ نویزگیری، GPU.

## آزمون

`Run-SelfTest.bat` (یا `dotnet run -c Release` در `src\PersianAiKit.Photo.SelfTest`): ۸ بخش — فهرستِ ابزارها و امنیتِ نسخه، هر ابزار روی عکسِ ساختگی با جوابِ معلوم (نوردهی، کنتراست، سیاه‌وسفید، دما، منحنی، HSL، برش، چرخش، قرینه، وینیت، شارپ، نویزگیری، مه‌زدایی، ترمیمِ لکه، همهٔ ۵۸ لغزنده در دو سر، ۱۴ فیلتر)، خودکار (عکسِ تیره، ته‌رنگِ شدید)، نمونه‌ها، حذفِ پس‌زمینه (زمینهٔ شیب‌دار با سایه و سوراخ، زمینهٔ شلوغ، انبردست در برابرِ ماسکِ BiRefNet، هاله و تمیزکاری، نگهبانِ حافظه)، هوشِ مصنوعیِ ساختگی (پاسخِ نیمه‌خراب، دو دور، بی‌کلید)، و کتابخانه/خروجی. نتیجه‌ها در `data\selftest\`.

- `--photos D:\pics` تنظیمِ خودکار روی عکس‌های خودتان.
- `--heavy` مدل‌های سنگین را هم می‌آزماید — **فقط روی سرورِ پرحافظه**؛ روی کامپیوترِ کم‌حافظه نگهبانِ حافظه خودش ردش می‌کند.
- `--write-docs` ساختنِ دوبارهٔ FEATURES.md؛ `--prompt` متنِ ثابتی که برای هوشِ مصنوعی فرستاده می‌شود.
