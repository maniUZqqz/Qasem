۳. گفتارِ طبیعی (چند صدا)

صداهای «طبیعی» با مدلِ Pocket ساخته می‌شوند (فقط استفادهٔ غیرتجاری)؛ روی این کامپیوتر برای هر ثانیه صدا حدودِ یک ثانیه وقت می‌گیرد. Piper سریع‌تر و ماشینی‌تر است.

۴. کلونِ صدای شما

با هدفون یا میکروفونِ خوب، در اتاقِ ساکت و بی‌پژواک، همیشه با یک فاصله. ۱ جمله کافی است تا صدا کار کند؛ ۵۰ جمله به بالا برای انتخابِ بهترین نمونه و ۳۰ تا ۶۰ دقیقه برای آموزشِ صدای اختصاصی روی سرور (VOICE-SETUP.md بخشِ ۶).
