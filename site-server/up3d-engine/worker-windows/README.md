# کارگرِ GPU روی ویندوز

کیفیت‌های «استاندارد»، «بالا (1080p)» و «4K» روی سرورِ بی‌کارتِ گرافیک عملاً اجرا نمی‌شوند (هر فریم چند دقیقه).
یک کامپیوتر با کارتِ گرافیکِ NVIDIA (مثلاً RTX 3060) همان کار را ده‌ها برابر سریع‌تر می‌کند.

## راه‌اندازی (یک بار)
1. **Python 3.10+** از python.org (هنگامِ نصب «Add python.exe to PATH» را بزنید).
2. **Blender 4.5 LTS** از blender.org (نصبِ معمولی در Program Files).
3. در پنل ⇐ «کارگرها» ⇐ یک کارگر بسازید (مثلاً `gpu-rtx3060`) ⇐ «فایلِ راه‌اندازیِ ویندوز» را بگیرید.
4. فایل را در یک پوشهٔ خالی (مثلاً `C:\up3d`) بگذارید و دوبار کلیک کنید.
   بارِ اول بستهٔ کارگر (هسته، موتور، دارایی‌ها، افزونهٔ کاراکتر) را از پنل می‌گیرد.
5. در پنل وضعیتِ کارگر «آنلاین» و «GPU» می‌شود؛ رندرهای باکیفیت خودکار به آن می‌رسند.

## نکته‌ها
- کارگر فقط به پنل وصل می‌شود (خروجی)؛ پورتی روی کامپیوتر باز نمی‌کند.
- کارتِ گرافیک خودکار پیدا می‌شود (OptiX ⇐ CUDA ⇐ HIP)؛ اگر نبود، با CPU کار می‌کند.
- سرعتِ واقعیِ هر کیفیت اندازه‌گیری و در پنل برای تخمینِ زمان استفاده می‌شود.
- اگر Blender جای دیگری است، در فایلِ bat خطِ `set "UP3D_BLENDER=..."` را باز کنید.
