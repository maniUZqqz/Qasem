# جذب مشتری (Growth Engine) — راهنما

**جذب مشتری** ابزارِ داخلیِ آپ‌مارکت (فقط برای کارکنان) است تا کسب‌وکارهایی را که می‌توانند مشتریِ ما شوند پیدا کنیم، راهِ تماسشان را از خودِ سایتشان جمع کنیم و با آن‌ها پیام‌رسانی کنیم؛ همه در همان پنلِ NMarketing (`http://87.107.160.17:8040/panel/` ← منوی «جذب مشتری»). این یک CRMِ عمومی نیست؛ فقط مسیرِ «پیدا کن ← راهِ تماس را بخوان ← پیام بده».

## جریانِ واقعیِ کار

```
۱. پیدا کردن          ۲. خواندنِ راهِ تماس              ۳. پیام دادن
کشف مشتری         ⇒   «استخراج» از سایتِ خودِ لید   ⇒   قالب ← کمپین ← آماده‌سازی ← بازبینی و تأیید ← شروع
(دستی یا CSV)         (تلفن، ایمیل، شبکه‌ها، فرم)       (ارسالِ خودکارِ فرمِ باز + صفِ دستیِ بقیه)
```

۱. **پیدا کردن:** آدرسِ سایت، پیجِ اینستاگرام (فقط ذخیره می‌شود؛ هرگز باز نمی‌شود)، نامِ کسب‌وکار یا یک فایلِ CSV. تکراری‌ها (با سایت/دامنه/اینستاگرام/تلفن/ایمیل) پیش از ثبت نشان داده می‌شوند و شما «ادغام» یا «رد» می‌کنید؛ هیچ‌چیز خودکار رونویسی نمی‌شود.
۲. **راهِ تماس:** برای لیدهایی که سایت دارند، «استخراج» صفحهٔ اصلی و صفحه‌های «تماس با ما/درباره ما/پشتیبانی» را می‌خواند (حداکثر ۵ صفحه، فقط همان سایت، با رعایتِ robots.txt) و فقط آنچه صفحه نشان می‌دهد ذخیره می‌کند؛ هر مورد صفحهٔ منبع، مدرک و «اطمینان» دارد.
۳. **پیام:** قالبِ فارسی با جاگذار (`{business_name}`، `{city}`…) ← کمپین ← سیستم صفحهٔ فرم را می‌گیرد و دقیقاً نشان می‌دهد چه چیزی ارسال می‌شود (dry-run) ← **شما هر آیتم را تأیید می‌کنید** ← ارسال با سقف و فاصله. فرمی که کپچا/ورود/… دارد **رد** می‌شود و به «صفِ دستی» می‌رود تا خودتان بفرستید.

**دورِ دوم (M3 تا M5):** پیدا کردنِ خودکار از **منبع‌های رایگان و مجاز** (نقشهٔ آزادِ OpenStreetMap؛ و اگر خودتان کلید بدهید API رسمیِ Brave/گوگل) · **کانال‌ها** (فرم، ایمیل با SMTPِ خودتان، پیامک از گوشیِ خودتان، و واتساپ/تلگرام/ایتا/بله/روبیکا/تماس به‌صورتِ دستی با لینکِ آماده) با اولویت، سقف و فاصلهٔ جدا برای هر کانال · **دانشِ محصول** و قالب‌های پیش‌فرضِ هر کانال، و یک **نویسندهٔ هوشمندِ اختیاری** که فقط از همان دانش می‌نویسد · یک امتیازِ ساده و بی‌AI برای «چقدر می‌شود به این لید رسید». همهٔ نگهبان‌های دورِ اول (تأییدِ انسانی، «تماس نگیر»، سقف، توقفِ اضطراری، بدونِ تلاشِ دوباره) برای همهٔ کانال‌های خودکار برقرار است.

> ارسالِ خودکار **پیش‌فرض خاموش** است و تا هویتِ راستینِ فرستنده (نام، شرکت، تلفن، ایمیل) کامل نشود روشن نمی‌شود. هر پیام با یک جملهٔ لغو تمام می‌شود. جزئیات و ریسک‌ها: `ARCHITECTURE.md` بخش ۸.

## تست‌ها

همهٔ تست‌ها با **HTTPِ شبیه‌سازی‌شده** اجرا می‌شوند (`httpx.MockTransport`)؛ در تست هیچ اتصالِ شبکه‌ای باز نمی‌شود (هر اتصال = شکستِ تست) و هیچ پیامی هیچ‌جا نمی‌رود. روی دیتابیسِ زنده هم اجرا نمی‌شوند: Django برای تست دیتابیسِ جدا و موقتی می‌سازد.
اجرا: روی یک **کپیِ آزمایشی** از `backend/` (بدونِ `.env`، بدونِ کلیدِ AI، با `SQLITE_PATH`/`MEDIA_ROOT`/`NM_DATA_DIR` در `/tmp` و `CELERY_TASK_ALWAYS_EAGER=true`) دستورِ
`python manage.py test apps.growth_engine --noinput`
را بزنید؛ یک ماژول: `… test apps.growth_engine.leads`. بایستی `OK` بدهد؛ تعدادِ تست‌ها در گزارشِ هر milestone آمده است. فرانت: `npx tsc --noEmit` و `vite build`.

## بازگشت (اگر لازم شد)

بکاپ و راهنمای دقیق: دورِ اول `/root/backups/nm-growth-m2-<تاریخ>/ROLLBACK.txt`، دورِ دوم `/root/backups/nm-growth-r2-20261104/ROLLBACK.txt`؛ خلاصه در `OPERATIONS.md` بخش ۸. هیچ تغییری روی جدول‌های موجودِ سایت نیست؛ بازگشت فقط این ابزار را برمی‌دارد.

## واژه‌نامه

| واژه | معنی |
|---|---|
| **لید** | یک کسب‌وکارِ احتمالیِ مشتری در دیتابیسِ جذب مشتری. (غیر از «لید» در ادمین ← CRM که پیامِ فرمِ تماسِ سایتِ عمومی است) |
| **کشف** | واردکردنِ لید: دستی یا از فایلِ CSV |
| **استخراج** | خواندنِ تلفن/ایمیل/شبکه‌های اجتماعی/نشانی/فرمِ تماس از صفحه‌های خودِ سایتِ لید |
| **راهِ تماس** | یک تلفن، ایمیل، سایت، اینستاگرام، فرمِ تماس… که به لید وصل است و منبعش مشخص است |
| **اطمینان** | عددِ ۰ تا ۱۰۰ که می‌گوید آن مقدار چقدر معتبر خوانده شده (مثلاً لینکِ `tel:` ۹۰، عددِ بی‌برچسب در متن ۵۰) |
| **کمپین** | مجموعه‌ای از لیدها با یک قالبِ پیام. یا «ارسال خودکار» یا «صفِ دستی» |
| **آماده‌سازی** | سیستم صفحهٔ فرمِ هر آیتم را می‌گیرد، تحلیل می‌کند و dry-run می‌سازد |
| **تأیید** | تصدیقِ شما برای یک آیتم، با همان متن و همان فرم؛ اگر متن یا فرم عوض شود باطل می‌شود |
| **صفِ دستی** | فرستادنِ دستی: متن را کپی می‌کنید، صفحه را باز می‌کنید، خودتان می‌فرستید و نتیجه را ثبت می‌کنید |
| **تماس نگیر** | فهرستی از شناسه‌ها که هرگز در صف نمی‌روند و چیزی دریافت نمی‌کنند |
| **توقفِ اضطراری** | کلیدِ قرمزی که همهٔ ارسال‌ها را فوراً می‌ایستاند |
| **سقفِ روزانه** | بیشینهٔ ارسال در یک روزِ تهران، سراسریِ همهٔ کمپین‌ها (پیش‌فرض ۴۰) |
| **dry-run** | نمایشِ دقیقِ آنچه ارسال خواهد شد، بدونِ ارسال |
