# مشتری‌یاب — دو اجرای واقعی روی وبِ زنده (۱۴۰۵/۰۸/۲۶، از سرورِ سایت، روی کپیِ آزمایشیِ دیتابیس)

هر دو اجرا با همان `manage.py crawl_run --preset …` و بودجهٔ پیش‌فرضِ پیش‌تنظیم انجام شد، روی **اینترنتِ واقعی** (نقشهٔ آزاد، فهرستِ بدن‌فیت، Bing، سایتِ خودِ کسب‌وکارها)، روی یک کپیِ آزمایشیِ دیتابیس (`/root/stage/leads/data`)، نه روی دیتابیسِ زنده. **هیچ پیامی فرستاده نشد** (در پایانِ اجرا: ۰ آیتمِ کمپین، ۰ تلاشِ ارسال). نام و شمارهٔ کسب‌وکارها عمداً در این سند نیامده؛ فقط عددها.

| | چغر ← باشگاه‌ها، مجموعه‌های ورزشی و مربی‌های شخصی — تهران | کافه‌های اصفهان |
|---|---|---|
| نوع‌ها / منبع‌ها | باشگاه بدنسازی، مجموعهٔ ورزشی، مربی شخصی؛ نقشه + فهرست + جست‌وجو + سایت | کافه؛ نقشه + جست‌وجو + سایت |
| زمانِ اجرا | ≈ ۱۷ دقیقه (۴۲۲ صفحه، ۳۳ مگابایت) | ≈ ۴٫۵ دقیقه (۴۱ صفحه، ۵٫۶ مگابایت) |
| پیداشده / پس از یکی‌کردنِ تکراری‌ها | ۱۶۸۳ ← ۷۲۶ کسب‌وکار | ۲۹۱ ← ۲۷۷ |
| **لیدِ تازه** | **۱۷۷** | **۱۲۹** |
| ردشده (هیچ راهِ تماسی پیدا نشد) | ۵۴۹ | ۱۴۸ |
| لیدهایی با موبایل | ۵۶ | ۶۴ |
| با تلفن (موبایل یا ثابت) | ۱۷۱ | ۱۲۷ |
| با سایت / ایمیل / اینستاگرام / تلگرام / فرمِ تماس | ۳۳ / ۱۵ / ۲۹ / ۹ / ۱۳ | ۱۳ / ۶ / ۱۴ / ۲ / ۴ |
| با مختصاتِ نقشه / ساعتِ کاری | ۱۱۹ / ۵۵ | ۱۲۹ / ۱۰۴ |
| امتیازِ تناسب: مناسب / متوسط / کم | ۱۵ / ۸۴ / ۷۸ | ۶ / ۶۲ / ۶۱ |
| منبعِ نامزدها | نقشه ۶۱۱، فهرستِ بدن‌فیت ۱۵۰ (۳۲۵ صفحهٔ فهرست و جزئیات)، سایت ۲۲، جست‌وجو ۴ | نقشه ۲۷۷، سایت ۱۰ |
| جست‌وجوی وب | ۸ پرسش، ۴۰ نتیجه، **۴ مرتبط** | ۳ پرسش، ۱۰ نتیجه، **۰ مرتبط** |
| کارهای ناموفق | ۰ | ۰ |

## آنچه دیدیم (صادقانه)

- **نقشه و فهرست دو ستونِ اصلی‌اند.** برای باشگاه‌های تهران نقشه ۶۶۸ مورد داد و فهرستِ بدن‌فیت ۱۵۰ باشگاهِ دارای تلفن؛ بیشترِ ۵۴۹ موردِ ردشده روی نقشه نام و مختصات دارند ولی نه تلفن دارند نه سایت (با «فقط دارای راهِ تماس» لید نمی‌شوند؛ با خاموش‌کردنِ آن گزینه لید می‌شدند).
- **جست‌وجوی وب از این سرور ضعیف است**: Bing برای پرسش‌های فارسیِ محلی نتیجه‌های بی‌ربط می‌دهد (در این دو اجرا از ۵۰ نتیجه فقط ۴ مرتبط بود)، DuckDuckGo «anomaly» و Mojeek کپچا. نتیجه‌های بی‌ربط درست کنار گذاشته شدند، چیزِ غلطی لید نشد.
- **مربی‌های شخصی** روی نقشه و در فهرست‌ها تقریباً نیستند؛ راهِ اصلیِ پیدا کردنشان پیش‌تنظیمِ «چغر ← مربی‌های آنلاین (اینستاگرام)» است که به سرورِ پردازش (آباگرام) نیاز دارد و تا روشن‌شدنش در صف می‌ماند.
- اجرای دوم همان مأموریت لیدها را **تکرار نمی‌کند** (شناسه‌ها و نام + مکان یکی می‌شوند؛ تست‌ها این را ثابت می‌کنند) و صفحه‌های گرفته‌شده از حافظه می‌آیند.
- از ۱۷۷ لیدِ چغر فقط ۵۶ تا موبایل دارند؛ بقیه تلفنِ ثابت یا فقط سایت/اینستاگرام. امتیازِ تناسب همین را در دلیل‌ها می‌گوید («تلفنِ ثابت دارد» ۶ امتیاز در برابرِ «موبایل» ۱۴).

## دورِ دوم — پس از اصلاحِ مشکل‌های بازبینی (۱۴۰۵/۰۸/۲۷)

بازبینِ مستقل روی سایتِ زنده دید که لیدهای اصفهان با برچسبِ «تهران» ساخته شده‌اند، دو شهر با هم یکی شده‌اند، مربی‌ها تقریباً نیستند و از صفحه‌ها ایمیلِ شخصی و شمارهٔ ساختگی برداشته شده. بعد از اصلاح دوباره روی **وبِ واقعی** و کپیِ آزمایشیِ دیتابیسِ زنده (که لیدهای اجرای اول را هم داشت و با `crawl_repair` پاک‌سازی شده بود) اجرا شد؛ هیچ پیامی نرفت.

| | چغر ← باشگاه‌ها و مربی‌ها — تهران | چغر ← مربی‌های آنلاین و پیج‌ها — چهار شهر |
|---|---|---|
| پیداشده / پس از یکی‌کردن | ۱۳۸۲ ← ۸۷۵ | ۱۲۴۳ ← ۵۴۳ |
| **کنار گذاشته شد چون نشانی/جایش شهرِ دیگری را می‌گفت** | ۵ | ۲۵ |
| ردشده: نوعِ دیگر (اسپا، تجهیزات …) / بی‌راهِ تماس | ۱۴ / ۵۲۷ | ۴ / — (۳۳۹ فقط به‌خاطرِ سقفِ ۲۰۰ لید) |
| لیدِ تازه / ادغام در لیدِ موجود | ۱۷۵ / ۱۵۹ | ۱۰۷ / ۹۳ |
| **مربی‌های واقعی از فهرستِ مربی‌ها** | ۲۵ (همه با تلفن یا واتساپ، ۱۶ با اینستاگرام) | ۴۷ (۶ تازه؛ ۲۶ با اینستاگرام) |
| شهرهای برنامه | تهران | تهران، اصفهان، مشهد، شیراز (هر کدام فهرست و پرسشِ جست‌وجوی خودش) |
| صفحه / زمان | ۳۲۳ صفحه، ≈ ۱۴ دقیقه | ۲۸۳ صفحه (۲۲۳ از حافظه)، ≈ ۱۱ دقیقه |
| کارِ ناموفق | ۰ | ۳ (فهرستِ بدن‌فیتِ شیراز: سایت خطا می‌دهد) |
| پیجِ اینستاگرام در انتظارِ سرورِ پردازش | — | ۴۰ |

- بازبینیِ پس از اجرا روی همهٔ لیدهای مأموریتِ تهران: با نشانی/جا/پیش‌شماره **۳۰۷ در تهران، ۳۸ بی‌مدرک، ۲ بیرونِ تهران** (هر دو لیدِ قدیمی که اجرای تازه داده‌هایش را ادغام کرده بود؛ برای همین قاعدهٔ «هرگز یکی نشدنِ دو شهر در سطحِ لید» هم اضافه شد). شمارهٔ نمونه: ۰، پیجِ اینستاگرامِ خودِ فهرست روی لید: ۰، لیدِ بی‌راهِ تماس: ۰.
- `crawl_repair` روی همان کپی: `crawl_repair --apply` روی کپیِ دادهٔ اجرای اول (۴۲۴ لید → ۳۳۷): ۸۷ لیدِ شهرِ دیگر/آمیخته/بی‌راهِ تماس پاک (۷ + ۷ + ۷۳؛ فقط ساختهٔ مشتری‌یاب و دست‌نخورده)، ۳۵ نتیجه از مأموریتِ تهران برداشته شد و لید شهرِ درستش را گرفت (برچسبِ «چغر · تهران» هم از آن لیدها رفت)، ۲۱ نامِ شهر یکدست شد، ۱۰ راهِ تماسِ غیرِ کسب‌وکار برداشته شد (۲ شمارهٔ نمونه، ۳ ایمیلِ شخصی کنارِ ایمیلِ خودِ کسب‌وکار، ۱ ایمیلِ طراح، ۱ موبایلِ اضافه، ۳ نشانیِ اینستاگرام/تلگرامِ ساختگی)، ۶۱ برچسبِ «مربی» از باشگاه‌های فهرستِ بدن‌فیت برداشته شد، متنِ ۴۲۵ ردیفِ تاریخچه ارقامِ فارسی گرفت. بار دوم اجرا هیچ کاری ندارد (بی‌تأثیرِ تکراری).
- جست‌وجوی وب هنوز برای مربی‌ها ۰ نتیجهٔ مرتبط می‌دهد (Bing)؛ مربی‌ها از فهرستِ مربی‌ها می‌آیند.

## دورِ سوم — پس از بازبینیِ زندهٔ دورِ دوم (۱۴۰۵/۰۸/۲۷، روی کپیِ دیتابیسِ زنده)

سه مأموریتِ واقعی (چغر ← تهران، کافه‌های اصفهان، چغر ← اینستاگرام با چهار شهر) با کدِ اصلاح‌شده روی کپیِ دیتابیسِ زنده اجرا شد؛ چیزی فرستاده نشد.

| مأموریت | زمان | پیداشده ← یکتا | لید (تازه / ادغام) | ردشده | نکته |
|---|---|---|---|---|---|
| چغر ← تهران | ۶ دقیقه | ۱٬۶۹۹ ← ۱٬۰۱۷ | ۱۱۶ / ۲۸۴ | ۶۱۷ (۶۰۷ سقفِ ۴۰۰ نتیجه، ۱۰ «نوعِ دیگر») | هر ۴۰۰ لید شهرِ تهران؛ ۳۵۷ صفحهٔ فهرست خوانده شد |
| کافه‌های اصفهان | ۱٫۵ دقیقه | ۲۹۲ ← ۲۸۰ | ۰ / ۱۲۹ | ۱۵۱ (۱۵۰ بی‌راهِ تماس، ۱ شهرِ دیگر) | همهٔ لیدها از اجراهای پیشین بودند؛ همه ادغام شدند |
| چغر ← اینستاگرام (۴ شهر) | ۲ دقیقه | ۱٬۲۴۳ ← ۵۴۳ | ۰ / ۲۰۰ | ۳۴۳ | **تهران ۸۹، اصفهان ۶۳، مشهد ۴۸، شیراز ۰**؛ ۴۰ کارِ پیج در صفِ ماندگارِ گره |

آنچه این دور نشان داد:

- **شهرِ خالی گفته می‌شود:** اجرای سه‌شهرهٔ اینستاگرام با پیامِ «تمام شد (برای ۴۰ کار منتظرِ سرورِ پردازش؛ برای شیراز چیزی پیدا نشد)» پایان یافت و هشدارِ «برای «شیراز» هیچ لیدی ساخته نشد. این منبع‌ها چیزِ تازه‌ای نیاوردند: جست‌وجوی وب، اینستاگرام» نوشت. بدن‌فیت صفحهٔ شیراز ندارد (۴۰۴): دیگر سه کارِ شکست‌خورده برایش ساخته نمی‌شود و اجرا همین را در گزارش می‌گوید.
- **Brave:** از این سرور در روزِ آزمایش ۴۰۳ می‌داد (آدرس را پس از چند درخواست محدود می‌کند). اولین ۴۰۳ موتور را ۳۰ دقیقه استراحت داد (DuckDuckGo ۲۰۲ و Mojeek ۴۰۳ هم)، پس از آن هیچ درخواستی به آن‌ها نرفت و دلیلِ طولانی فقط یک بار در گزارش آمد. نتیجهٔ جست‌وجوی وب در این روز فقط از Bing (پرسِ انگلیسی) بود: ۱۰ نتیجه، ۱ مرتبط. **از یک کامپیوترِ دیگر** (دفتر) یک درخواستِ Brave ۲۰ نتیجهٔ درست داد: برای `site:instagram.com مربی بدنسازی تهران` ۲۰ پیجِ مربی با دنبال‌کنندهٔ عمومیِ چاپ‌شده در شرح (مثلاً «21K Followers») که تجزیه‌گر بی‌خطا خواند و شهرِ نام‌برده در عنوان را شاهد گرفت (پیجی با «شیراز📍» برای مأموریتِ تهران کنار رفت). پس راهِ حلِ پایدار کلیدِ API برِیو است (کارِ مالک، بخشِ ۹ در `modules/crawler.md`).
- **پیامک:** برای هر سه مأموریت (مأموریتی با معرفیِ کامل، مأموریتی که فرمش `pitch: {}` ذخیره کرده بود، و کافه‌ها) پیش‌نویسِ پیامک جملهٔ کامل و دو بخش است و هشدار ندارد؛ مثلاً: «سلام، از تیمِ «چغر». دستیارِ هوش مصنوعیِ مربی‌ها؛ شروعِ رایگان. / اگر مایل به دریافت پیام نیستید، پاسخ دهید «لغو».»
- `crawl_repair --apply` روی همان کپی: ۷ لیدِ «نوعِ دیگر» (اسپا، فروشگاهِ تجهیزات، کلینیک، پاراگلایدر، ماساژ، رقص) و ۲ لیدِ فقط‌با‌سایتِ‌رسانه‌ای/فهرست (آپارات، cybo) پاک شد؛ «اسپاد فیت»، «اسپاتنا» و «اسپارتا» ماندند؛ لیدی که آدمی رویش کار کرده بود فقط نتیجه‌بودنش را از دست داد؛ لیدِ «فیت لند آقایان» با جای اصفهان دیگر در تهران نیست؛ ۳۴۰ لید دسته گرفت؛ ۲۶ مربیِ فهرست برچسبِ «فرد مستقل» خورد؛ ۶۲ باشگاه «مربی» را از نوعشان از دست دادند؛ دومین اجرا چیزی گزارش نداد.

## چگونه دوباره اجرا کنید

```
cd /var/www/NM/upmarket/backend
../venv/bin/python manage.py crawl_run --preset chagher_gyms_tehran      # یا cafes_isfahan
```

یا از پنل: جذب مشتری ← مشتری‌یاب ← «شروعِ سریع» ← «بساز و اجرا کن».
