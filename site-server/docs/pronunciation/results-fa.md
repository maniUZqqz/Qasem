# نتیجهٔ سنجشِ صدا ← تشخیصِ گفتار (اندازه‌گیریِ اولیه، دورِ دوم)

جمله‌های ثابت × دو بار (پیش/پس). تشخیصِ گفتار: Vosk فارسیِ کوچک (vosk-model-small-fa-0.42) / پردازنده، روی سرورِ سایت. Piper با نویزِ صفر (تکرارپذیر). «خطا» = نرخِ خطای واژه؛ کمتر بهتر. Piper روی **gyro** است، صدایی که این سایت واقعاً دارد (gyro، mana، ganji)؛ **هر عدد برای یک صدا و یک عمقِ لایه است.**
این اندازه‌گیری با رکابِ کوچکِ Vosk است؛ جدولِ Whisper روی کارتِ گره، با روشن شدنِ گره، خودکار در پنل (صدا › تلفظ › سنجشِ صدا) جایش را می‌گیرد و پیش‌فرضِ هر موتور را خودش به عمقِ بهتر می‌برد.
