# سایت عمومی آپ‌مارکت

سایت بازاریابی و فروش — جدا از پنل محصول (`../frontend`).

```bash
cp .env.example .env.local
npm install
npm run dev        # http://127.0.0.1:3001
```

## چرا Next.js و نه همان Vite پنل

سایت عمومی باید در گوگل دیده شود. رندر سمت سرور، متادیتای هر صفحه،
`sitemap.xml` و داده‌ی ساخت‌یافته چیزهایی‌اند که یک SPA به‌سختی می‌دهد.
پنل محصول این نیاز را ندارد (پشت لاگین است) و همان Vite می‌ماند.

## صفحات

| مسیر | چیست |
|---|---|
| `/` | صفحه‌ی اصلی — هیرو با **نمونه‌ی خروجی واقعی**، مشکل، راه‌حل، فرایند |
| `/features` | شش قابلیت، هرکدام با جزئیات واقعی |
| `/how-it-works` | شش قدم از ثبت محصول تا انتشار |
| `/pricing` | **قیمت‌ها زنده از بک‌اند** + مقایسه با تیم داخلی |
| `/showcase` | نمونه‌کار واقعی — از `content/showcase/works.json` |
| `/blog` · `/blog/[slug]` · `/blog/tag/[tag]` | وبلاگ از Markdown، با صفحه‌ی موضوع |
| `/about` · `/faq` · `/contact` | اعتمادسازی |
| `/sitemap.xml` · `/robots.txt` · `/feed.xml` | خودکار، شامل مقالات و تگ‌ها |
| `/opengraph-image` · `/icon` | تصاویر اشتراک‌گذاری، تولید داینامیک |

## سئو

| مورد | وضعیت |
|---|---|
| داده‌ی ساخت‌یافته | Organization · WebSite · BreadcrumbList · Product/Offer · FAQPage · HowTo · BlogPosting |
| تصویر اشتراک‌گذاری | تولید داینامیک — هر مقاله کارت اختصاصی خودش را دارد |
| canonical | روی همه‌ی صفحات |
| sitemap | ۲۶ نشانی شامل مقالات و صفحات تگ |
| RSS | `/feed.xml` |
| دسترسی‌پذیری | لینک «پرش به محتوا»، فوکوس قابل‌دیدن، تگ‌های معنایی |
| تصاویر | `width`/`height` مشخص برای جلوگیری از پرش چیدمان |

**نکته‌ی فونت تصاویر:** موتور تصویرسازی (Satori) نمی‌تواند خط عربی را شکل
بدهد و حروف فارسی را جدا از هم رندر می‌کند. برای همین وزیرمتن از `assets/`
صریح به آن داده می‌شود. آن پوشه را حذف نکن.

## قانون قیمت

**هیچ قیمتی در این پروژه نوشته نشده.** صفحه‌ی `/pricing` از
`GET /api/v1/plans/` می‌خواند، و آن پلن‌ها با `python manage.py seed_plans`
از `دیتا/0-منبع/data.json` ساخته می‌شوند.

```
دیتا/0-منبع/data.json  →  seed_plans  →  دیتابیس  →  /api/v1/plans/  →  /pricing
```

یعنی قیمتی که در سایت دیده می‌شود همان است که بک‌اند اجرا می‌کند و همان که
در ارائه آمده. `lib/plans.ts` یک نسخه‌ی پشتیبان دارد که فقط وقتی API در
دسترس نباشد استفاده می‌شود، و آن موقع در صفحه اعلام می‌کند.

## نمونه‌کارها

`scripts/sync-showcase.mjs` تصاویر و کپشن‌ها را از `دیتا/` به داخل پروژه
کپی می‌کند و به‌صورت `prebuild` خودکار اجرا می‌شود. این کار عمدی است: صفحه
نباید در زمان رندر به پوشه‌ای بیرون از پروژه وابسته باشد، چون بعد از deploy
آن پوشه وجود ندارد.

```bash
npm run sync     # دستی، وقتی نمونه‌ی جدیدی اضافه شد
```

## افزودن مقاله

یک فایل `.md` در `content/blog/` بساز:

```markdown
---
title: عنوان مقاله
description: توضیح یک‌خطی برای گوگل و کارت مقاله
date: ۱۴۰۴/۰۶/۱۵
author: تیم آپ‌مارکت
tags: [بازاریابی, فروش]
---

متن مقاله...
```

زمان مطالعه، صفحه‌ی تگ، مقالات مرتبط، کارت اشتراک‌گذاری، `sitemap.xml`،
RSS و متادیتای SEO همه خودکارند.

**نکته‌ی محتوایی:** تگ‌ها را کم و ثابت نگه دار. هر تگ یک صفحه می‌سازد، و ده
صفحه‌ی تگ با یک مقاله در هرکدام به سئو ضرر می‌زند نه سود.

## تم و زبان

دو تم (روشن/تیره) با ذخیره‌ی انتخاب در مرورگر. یک اسکریپت کوچک در
`layout.tsx` قبل از رنگ‌آمیزی صفحه اجرا می‌شود تا کاربری که تم تیره را
انتخاب کرده هرگز یک لحظه صفحه‌ی سفید نبیند.

سایت فارسی و RTL است، و **مسیر `/en` هم ساخته شد** — `lib/i18n.ts`،
با `alternates` و `hreflang` روی هر صفحه.

مقاله‌های وبلاگ عمداً فقط فارسی‌اند: ترجمه‌ی ماشینی یک مقاله‌ی سئو، صفحه‌ای
می‌سازد که برای هیچ عبارتی رتبه نمی‌گیرد و اعتبار دامنه را هم پایین می‌آورد.

## ساختار

```
app/                 صفحات (App Router)
  opengraph-image    کارت اشتراک‌گذاری سایت
  icon               آیکون تولیدشده
  feed.xml/          RSS
components/          Header، Footer، ThemeToggle، SectionHead، JsonLd
lib/content.ts       همه‌ی متن‌های بازاریابی — یکجا
lib/plans.ts         خواندن قیمت از API
lib/blog.ts          خواندن مقالات از Markdown
lib/seo.ts           سازنده‌های داده‌ی ساخت‌یافته
content/blog/        مقالات
content/showcase/    نمونه‌کارها (تولیدشده با sync)
assets/              وزیرمتن برای تصاویر — حذف نشود
public/showcase/     مدیای نمونه‌کار (تولیدشده با sync)
scripts/             sync-showcase.mjs
```

## استایل

استایل‌ها در `app/globals.css` هستند، نه inline. توکن‌های رنگ در `:root`
تعریف شده‌اند و تم تیره فقط همان توکن‌ها را عوض می‌کند — نه هر کلاس را.
کلاس‌های کاربردی (`.wrap`, `.card`, `.grid`, `.checks`, `.stat`, …) برای
همین هستند که HTML سبک بماند و خزنده‌ی گوگل محتوا را راحت‌تر بخواند.
