# UpMarket 3D روی کامپیوترِ دارای کارتِ گرافیک (ویندوز)

همه‌چیز داخلِ همین پوشه است: پایتون، کتابخانه‌ها، Blender 4.5، FFmpeg، کاراکترها و دارایی‌ها،
و **کپیِ کاملِ دیتابیس و پروژه‌های سرور** (تا لحظهٔ ساختِ این زیپ). نصبِ چیزی لازم نیست.
اینترنت فقط برای کارگردانِ هوشِ مصنوعی و صدای فارسی (Metis) لازم است؛ رندر و بقیه بی‌اینترنت کار می‌کنند.

## اجرا
1. زیپ را در یک مسیرِ **کوتاه و بی‌فاصله** باز کنید، مثلاً `D:\UpMarket3D` (حدودِ ۲٫۵ گیگابایت جا).
2. **`start.bat`** را دوبار بزنید. بارِ اول Blender را باز می‌کند (چند دقیقه).
3. مرورگر خودش `http://127.0.0.1:8030` را باز می‌کند. کاربر **admin**، رمز در `data\admin-password.txt`.
4. خاموش کردن: **`stop.bat`**.

## کارهای مانده که خودکار انجام می‌شوند
کارگرِ همین کامپیوتر (`local-gpu`) به‌محضِ روشن شدن کارهای در صف را برمی‌دارد — با کارتِ گرافیک خیلی سریع‌تر از سرور:
- ویدئوی واقع‌گرایانهٔ «عطر رز» (پیش‌نمایش) و **همان ویدئو با کیفیتِ بالا (1080×1920)**
- تصویرِ همهٔ کاراکترها، محیط‌ها، محصول‌ها و ویدئوی کوتاهِ همهٔ حرکت‌ها (کتابخانهٔ دارایی‌ها)
- نمونهٔ فریمِ کیفیتِ استاندارد، خروجیِ GLB و «بستهٔ بازیِ کاراکتر»
وضعیت: پنل ⇐ «کارها». پنجرهٔ «UP3D worker» هم پیشرفت را نشان می‌دهد.

## آزمونِ این کامپیوتر
**`test.bat`**: آزمون‌های هسته + این‌که Blender کارتِ گرافیک را می‌بیند (OptiX/CUDA) + ساختِ یک ویدئوی کوتاه از سر تا ته.

## دو حالتِ استفاده
| حالت | فایل | کِی |
|---|---|---|
| مستقل | `start.bat` | همه‌چیز روی همین کامپیوتر (پنل، پروژه‌ها، رندر) |
| کارگرِ سرور | `start-worker-for-server.bat` | پروژه‌ها روی سرور (`http://87.107.160.17:8030`) می‌مانند و فقط رندرِ باکیفیت این‌جا انجام می‌شود |

## کیفیت
در صفحهٔ هر پروژه ⇐ «رندر»: انیمیک، پیش‌نمایش، استاندارد (720p)، **بالا (1080p)**، 4K.
با کارتِ گرافیک، «بالا» و «4K» عملی‌اند (روی سرورِ بی‌GPU هر فریم چند دقیقه طول می‌کشید).
خروجیِ سه‌بعدی: GLB (وب/بازی)، «بستهٔ بازیِ کاراکتر» (هر حرکت یک انیمیشنِ جدا برای Unity/Unreal/Godot)، FBX، BLEND.

## ساختارِ پوشه
```
start.bat · stop.bat · test.bat · start-worker-for-server.bat
up3d\  engine\  assets\  web\  tests\  docs\     کدِ کاملِ پروژه (همان سرور)
vendor\python\        پایتونِ قابلِ حمل + vendor\pylibs\ کتابخانه‌ها
vendor\blender\       Blender 4.5 LTS (بارِ اول از vendor\blender-windows.zip باز می‌شود)
vendor\blender-user\  افزونهٔ کاراکتر (MPFB2) + پوست، مو، لباس، چهره
vendor\ffmpeg\        FFmpeg
data\                 دیتابیس، پروژه‌ها، خروجی‌ها (پشتیبان بگیرید)
```

## اگر مشکلی بود
- پنل باز نشد: پنجرهٔ «UP3D panel» را از نوارِ وظیفه باز کنید و خطا را ببینید؛ پورتِ 8030 نباید اشغال باشد.
- GPU پیدا نشد: درایورِ کارتِ گرافیک (NVIDIA Studio/Game Ready) را به‌روز کنید؛ بدونِ GPU هم با CPU کار می‌کند.
- کلیدِ هوشِ مصنوعی/صدا: پنل ⇐ «تنظیمات (ادمین)» ⇐ «تنظیماتِ هوشِ مصنوعی و صدا» (همان کلیدِ Metis ِ سرور در این کپی هست).
