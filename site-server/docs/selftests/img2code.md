# «تصویر به کد» — آزمونِ پذیرش

«تصویر به کد» روی **CPU ِ سرورِ سایت** اجرا می‌شود (یک تبدیلِ معمولی ۴ تا ۹ ثانیه و کمتر از ۲۵۰ مگابایت رم)، پس **نوعِ کارِ جدیدی برای سرورِ پردازش (GPU)** ندارد و
هیچ بخشی از آن منتظرِ روشن‌شدنِ سرورِ پردازش نیست. با این حال در «آزمونِ خودکارِ سرورِ پردازش» یک **آزمونِ مجازی (بی‌گره)** ثبت شده تا همراهِ بقیه هر شب و با هر بار روشن‌شدنِ گره
خودش اجرا شود و در پنل دیده شود:

* **`img2code_engine`** (`backend/apps/compute/selftests/img2code.py` ⇒ `apps.img2code.selftest.run_engine`): یک صفحهٔ کوچکِ ساختگی از آغاز تا سندِ سایت‌ساز:
  وارسیِ موتور (mv2code، Tesseract فارسی+انگلیسی، مرورگرِ بی‌سر) ⇒ تبدیل در پردازهٔ جدا با سقفِ حافظه و زمان ⇒ نمایش و سنجشِ شباهت در مرورگر ⇒ درخت ⇒ سندِ سایت‌ساز (`clean_doc`).
  قبول = همهٔ مرحله‌ها؛ وگرنه نامِ مرحلهٔ ردشده و دلیلش در گزارش می‌آید. هم‌زمان با تبدیل‌های کاربر فقط یکی اجرا می‌شود (همان قفلِ فایلی)؛ اختیاری است (در نتیجهٔ کلیِ گره نمی‌آید).

همین آزمون را با دست هم می‌شود زد (کدِ خروج ۰ ⇐ همه PASS):

```
cd /var/www/NM/upmarket/backend
../venv/bin/python manage.py img2code_check                       # یک صفحهٔ کوچکِ ساختگی از آغاز تا سندِ سایت‌ساز
../venv/bin/python manage.py img2code_check --url https://chagher.ir/   # و عکس‌گرفتن از یک نشانیِ عمومی
```

آزمون‌های واحد: `manage.py test apps.img2code` (نقشه‌بردار، محافظِ نشانی، API و مجوزِ هر فروشگاه، سقفِ حافظه و زمان، ساختِ پیش‌نویسِ سایت‌ساز، سندِ طراحیِ UI، و یک تبدیلِ واقعیِ کوچک که بدونِ موتور skip می‌شود).
مرورگری (Playwright روی صفحهٔ واقعی با CSSِ واقعیِ پنل، دسکتاپ و گوشی): `IMG2CODE_BROWSER=1 manage.py test apps.img2code.tests_browser`.
سنجشِ «چغر»: `IMG2CODE_CHAGHER_URL=https://chagher.ir/ manage.py test apps.img2code.tests_chagher`.

## اگر روزی بخواهیم OCR ِ دقیق‌تر روی GPU باشد (وصل نشده)
`mv2code.convert(..., ocr_lines=[{box:[x,y,w,h], text, conf}])` خطوطِ متن را از هر موتورِ دیگری می‌پذیرد. کارِ پیشنهادی: نوعِ کارِ `img2code.ocr` روی گره (EasyOCR با GPU، ماژولِ
`processing/img2code_jobs.py`) که تصویر را می‌گیرد و `lines` برمی‌گرداند؛ سایت همان را به `--lines` بدهد. تا آن روز Tesseract (≈۱۴٪ خطای نویسه روی نوشتهٔ ریزِ فارسی) و، برای نشانیِ صفحه، متنِ DOM (۰٪ خطا) است.
