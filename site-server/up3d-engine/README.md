# UpMarket 3D — موتورِ ساختِ ویدئوی تبلیغاتیِ سه‌بعدی با هوشِ مصنوعی

از یک جملهٔ فارسی («این عطر را یک خانم بردارد، نشان بدهد و دعوت به خرید کند») تا یک ویدئوی تبلیغاتیِ کامل:
کارگردانِ هوشِ مصنوعی صحنه را می‌نویسد، موتورِ سه‌بعدی (Blender 4.5 LTS) انسانِ واقعی‌نما، حرکت، محصول، محیط، نور و دوربین را می‌سازد و رندر می‌کند،
صدای فارسی با هماهنگیِ لب، زیرنویس و دعوت به خرید روی آن مونتاژ می‌شود و کنترلِ کیفیتِ خودکار نتیجه را می‌سنجد.

- **پنل:** `http://87.107.160.17:8030` (کاربر `admin`، رمز در `data/admin-password.txt`)
- **تنظیمِ هوشِ مصنوعی و صدا:** جنگو ادمین ⇐ «تنظیماتِ هوشِ مصنوعی و صدا» (Base URL، کلید، مدل؛ Metis/OpenAI/هر سرویسِ سازگار)
- **ایده و معماری:** `docs/IDEA.md` · راهنمای کامل داخلِ پنل: `/docs/`

## سه راهِ ساخت، یک سند
| راه | کجا |
|---|---|
| هوشِ مصنوعی | «پروژهٔ تازه» یا تبِ «ویرایش با هوشِ مصنوعی» در هر پروژه |
| محیطِ گرافیکی | خطِ زمانِ شش‌شیاره (دوربین، حرکت، گفتار، چهره، نگاه، نوشته) + بازرس + وارسیِ زنده |
| کد | `up3d.sdk.Scene` (پایتون)، `python -m up3d` (خطِ فرمان)، REST API (`/api/v1/…`) |

همه «سندِ صحنه» (`up3d.scene/1`) می‌سازند؛ وارس‌گر و ترمیم‌گر همیشه پیش از رندر اجرا می‌شوند.

## خروجی‌ها
- **ویدئو:** MP4 (9:16، 16:9، 1:1، 4:5) — انیمیک، پیش‌نمایش، 720p، 1080p، 4K
- **بازی/وب:** GLB (glTF 2.0) با انیمیشنِ پخته، حالت‌های چهره و دوربین‌ها + نمایشگرِ سه‌بعدیِ داخلی
- **نرم‌افزارهای سه‌بعدی:** FBX، USD، BLEND

## مدیریت روی سرور
```bash
cd /var/www/NM/3D
./up3d.sh status            # وضعیتِ سرویس‌ها
./up3d.sh restart
./up3d.sh logs worker       # web | orchestrator | worker
./up3d.sh test              # آزمون‌های هسته
./up3d.sh bundle            # بستهٔ کارگرِ GPU برای ویندوز
./up3d.sh backup            # پشتیبانِ دیتابیس و خروجی‌ها
./up3d.sh admin USER PASS   # کاربرِ مدیر
```
سرویس‌ها: `up3d-web` (gunicorn، سوکت)، `up3d-orchestrator` (برنامه‌ریزی، صدا، لب، مونتاژ، کنترلِ کیفیت)، `up3d-worker` (رندرِ CPU با اولویتِ پایین).
nginx: `/www/server/panel/vhost/nginx/port_8030.conf`. به ARKA (8000) و solo (8010/8020) دست نخورده است.

## سخت‌افزار و کیفیت
سرورِ فعلی ۲ هستهٔ CPU و بی‌کارتِ گرافیک است ⇐ انیمیک (~۰٫۶ ثانیه/فریم) و پیش‌نمایشِ Cycles روی سرور؛
کیفیت‌های ۷۲۰p/۱۰۸۰p/۴K به «کارگرِ GPU» می‌روند: پنل ⇐ کارگرها ⇐ فایلِ راه‌اندازیِ ویندوز (PC با RTX).
همان صحنه روی سیستمِ قوی‌تر خودکار با نمونهٔ بیشتر، وضوحِ بالاتر، پوستِ زیرتقسیم‌شده و تاریِ حرکت رندر می‌شود.

## ساختار
```
up3d/            هستهٔ مستقل از موتور: سند، دارایی‌ها، وارسی+گرافِ حرکت+ترمیم، compiler، کارگردانِ AI، قالب‌ها،
                 صدا (TTS)، لبِ فارسی (ویسم)، برچسبِ محصول، نوشتهٔ فارسی، مونتاژ (FFmpeg)، کنترلِ کیفیت، خط، کارگر، SDK، CLI
engine/          داخلِ Blender: کاراکتر (MPFB/فایل)، ریگِ کنترلی (IK دست و پا، نگاه، انگشت)، ۱۴ حرکتِ رویه‌ای، چهره (ویسم، پلک، حالت)،
                 محصول (ساخت، برچسب، گرفتن، چسبیدن به دست)، محیط، نور، دوربین، پختن+اندازه‌گیری، رندر، خروجی
engine/rigs/     نقشهٔ نقشِ استخوان‌ها (کاراکترِ تازه با اسکلتِ دیگر = یک فایلِ JSON)
assets/          دفترِ دارایی‌ها (هر کدام پوشه + manifest.json) + فونتِ وزیرمتن
web/             پنل Django + DRF (فارسی، راست‌به‌چپ)
worker-windows/  راه‌اندازیِ کارگرِ GPU روی ویندوز
deploy/          systemd و nginx
tests/           آزمون‌های هسته و آزمونِ سرتاسریِ API
data/            دیتابیس، کارها، بارگذاری‌ها، کش (پشتیبان بگیرید)
vendor/          Blender 4.5.14 LTS + افزونهٔ MPFB2 + دارایی‌های CC0 (پوست، مو، لباس، چهره، ویسم)
```
