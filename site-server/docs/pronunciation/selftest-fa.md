# آزمونِ خودکارِ گره برای «تلفظ»

ثبت‌شده در `backend/apps/compute/selftests/pron.py` (کلید `pron_piper`، دستهٔ «صدا»). با روشن شدنِ گره و عاملِ تازه، خودکار اجرا می‌شود (چارچوبِ آزمونِ سرورِ پردازش).

**کارِ واقعی** (`voice.pron_eval`، یک کارِ کوچک):

```json
{"engine": "piper", "voice": "fa_IR-amir-medium", "language": "fa",
 "items": [{"id": 0,   "variant": "before", "text": "<جملهٔ ۰ از eval_set، متنِ خام>"},
           {"id": 0,   "variant": "after",  "ipa": ["<IPAی لایه برای همان جمله؛ واژه‌های ناشناخته {{واژه}}>"]},
           "... همین‌طور برای جمله‌های ۳۰، ۶۱، ۱۱۴، ۱۳۴، ۱۴۹ (ع، ه، و/او، اضافه، عدد، تاریخ)"]}
```

گره: Piper (محیطِ `venvs/pron`، صدای amir) هر دو را می‌گوید، Whisper (محیطِ `asr`، کارت) گوش می‌دهد و `result.json` برمی‌گرداند:

```json
{"engine": "piper", "voice": "...", "asr": {"model": "faster-whisper-small", "device": "cuda", "compute_type": "float16", "note": ""},
 "items": [{"id": 0, "variant": "before", "hyp": "...", "audio_s": 3.1, "synth_s": 0.4}, "..."]}
```

**شرطِ قبول** (`check`): (۱) بیش از ۸۰٪ فایل‌ها چیزی شنیده شد؛ (۲) نرخِ خطای واژه «پس» ≤ ۶۰٪؛ (۳) «پس» از «پیش» بیشتر از ۱۵ واحدِ درصد بدتر نشد. تشخیصِ گفتار روی پردازنده = هشدار (نه رد).
وقتی قبول شد، `evalrun.ensure_full_runs()` سنجشِ کامل (۲۳۰ جمله) را برای Piper (و Edge اگر سیاستِ سکو اجازه دهد، و MOSS اگر روی گره نصب است) در صفِ ماندگار می‌گذارد.

نصبِ پیش‌نیازها (Piper، دو صدا، Whisper) خودکار است (`requirements.d/pron.json` و `asr-gpu.json`)؛ تا آماده شدن، کار در صف می‌ماند و آزمون «منتظرِ نصب» می‌گوید.
